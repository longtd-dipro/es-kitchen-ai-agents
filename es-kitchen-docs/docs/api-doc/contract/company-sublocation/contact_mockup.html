種別 (contactType / role): MAIN = nguồn của login_id · BILLING = người nhận hóa đơn · SUB = phụ trách phụ.

ログインアカウント Tài khoản đăng nhập

読み取り専用 · read-only
login_id lấy từ contact MAIN (email). Đổi email MAIN → login_id đổi theo.
ISO 8601 | null — null = chưa từng đăng nhập.

Cấp phát / phát hành lại tài khoản (gửi mật khẩu) là thao tác của E03 System Admin — POST /admin/companies/bulk-issue-accounts. E02 không có nút phát hành tài khoản trên màn hình này.

{ } API仕様 — 担当者 (E02)

Endpoints

GET /company-admin/company/contacts AdminCompanyGuard
PATCH /company-admin/company/contacts AdminCompanyGuard

Account issuance (phát hành tài khoản + gửi mật khẩu) là thao tác E03: POST /admin/companies/bulk-issue-accounts — không thuộc màn hình E02 này.

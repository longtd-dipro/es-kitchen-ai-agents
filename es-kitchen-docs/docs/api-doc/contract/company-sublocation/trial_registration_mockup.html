無料トライアル申込 Đăng ký dùng thử
Form công khai cho doanh nghiệp đăng ký dùng thử ESSTATION — không cần đăng nhập.
💡
Sau khi gửi, hệ thống tạo một trial_request với trạng thái PENDING. E03 (System Admin) sẽ duyệt đơn và cấp tài khoản đăng nhập qua email tới địa chỉ người phụ trách. Đây là endpoint công khai (no guard).

{ } API仕様 — 無料トライアル申込 (Public)

Endpoint

POST /public/trial-requests No guard · Public

Request body — CreateTrialRequest

{
  // === 法人情報 ===
  "companyName": "株式会社サンプル",        // required · maxLength 100
  "companyNameKana": "カブシキガイシャサンプル", // optional · katakana
  "postalCode": "123-4567",               // optional · /^\d{3}-\d{4}$/
  "addressPrefecture": "東京都",           // optional
  "addressCity": "渋谷区",                 // optional
  "addressStreet": "代々木1-2-3",          // optional
  "addressBuilding": "サンプルビル 5F",     // optional
  "employeeCount": "50",                  // optional
  "tel": "03-1234-5678",                  // optional
  "fax": "03-1234-5679",                  // optional
  "paymentMethod": "クレジット決済",        // optional

  // === ご担当者 ===
  "contactName": "山田太郎",               // required · maxLength 100
  "contactTel": "090-1234-5678",          // optional
  "contactEmail": "yamada@example.co.jp", // required · @IsEmail()

  // === ご希望 ===
  "desiredPlan": "300プラン",              // optional
  "contractStartMonth": "2026/07",        // optional · format YYYY/MM
  "note": "...",                          // optional

  // === 同意 ===
  "termsAgreed": true                     // required · phải = true
}

Response — 201 Created

{
  "id": "1234567890",   // trial_request id (bigint as string)
  "status": "PENDING"   // trạng thái khởi tạo
}

Flow

BướcKết quả
Public submit formtạo trial_request · status = PENDING
E03 duyệtcấp tài khoản (Cognito) + gửi email mật khẩu cho người phụ trách

Errors

HTTPCode
400TERMS_MUST_BE_AGREED (termsAgreed ≠ true)
400validaton_error (thiếu field bắt buộc / sai format — data là array lỗi per-field)

Prefix /public = route công khai, không gắn guard. Required: companyName · contactName · contactEmail · termsAgreed.

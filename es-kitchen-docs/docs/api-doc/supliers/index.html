1 · Convention API

Phân hệBase pathAuth
Admin · 仕入先マスタ/admin/supplier-mastersAdmin JWT (Bearer)
Admin · アカウント発行/admin/supplier-masters/accounts/issueAdmin JWT + perm supplier_account.issue
Supplier self-service/supplier/... · /auth/supplier/...Supplier JWT (Bearer)

Response envelope

// Success
{ "statusCode":"success",
  "message":"...", "data": <T> }
// Error
{ "statusCode":"validation_error|...",
  "message":"i18n", "title":"...",
  "errorCode":"SUPPLIER_NAME_REQUIRED",
  "data": null }

List / pagination

// Query: page(1) limit(10) sort order(DESC)
// List endpoints (flat):
{ "items":[...], "total", "page",
  "limit", "totalPages" }
// History endpoint dùng meta{}:
{ "items":[...], "meta":{ total,page,limit,totalPages } }
⚠️
Lưu ý nhất quán: list 仕入先マスタ trả phẳng (items/total/page/limit/totalPages), riêng :id/history bọc trong meta{}. FE đọc đúng theo từng endpoint trong contract.

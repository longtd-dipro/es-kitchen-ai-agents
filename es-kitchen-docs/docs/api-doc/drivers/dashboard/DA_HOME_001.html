FIELD LEGEND

📌 API: All fields on this screen are populated via GET /driver/home (Driver Home). Annotation numbers correspond to fields in the API Response DTO.
① Header / Driver Info（ヘッダー情報）
# Field / Trường Type / Kiểu Source API Response / Nguồn API
(1)
Driver Name / Welcome Message
Tên tài xế / Lời chào
 string GET /driver/home
Field: driverName
Pattern: {name} さん、安全運転で...
② KPI Section — 本日の配送状況（Today's Delivery Status）
#Field / TrườngType / KiểuSource API Response / Nguồn API
(1)
本日の配送件数
(Today's Total Deliveries)
Tổng số lượt giao hôm nay
 number GET /driver/home
Field: kpi.todayTotal
(2)
完了件数
(Completed Count)
Số lượt đã hoàn thành
 number GET /driver/home
Field: kpi.completed
(3)
残り件数
(Remaining Count)
Số lượt còn lại
 number GET /driver/home
Field: kpi.remaining
Computed: todayTotal - completed
(4)
本日の進捗率
(Today's Progress %)
Tỷ lệ tiến độ hôm nay
 number GET /driver/home
Field: kpi.progressPercent
Computed: completed / todayTotal × 100

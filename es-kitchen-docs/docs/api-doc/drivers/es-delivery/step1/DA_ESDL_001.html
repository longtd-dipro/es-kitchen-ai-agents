#UI / 操作Hành độngRequest field (ráp DTO)

Request body ví dụ（multipart）

POST /driver/shipments/{shipmentId}/companies/{companyId}/step1/photos

FormData:
- files: File[]
- beforeStockPhotoUrls?: string[]
FE は upload 成功後に beforeStockPhotoUrls を保持し、Step 2/3 の送信や表示に再利用する。 必須は「最低1枚」など要件があるなら validation 側で制御する。

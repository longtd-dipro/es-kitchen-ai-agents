Bảng B: Ráp Request DTO (POST complete)

Thao tác ⇒ body của POST /driver/receipts/{receiptId}/complete

#UI / 操作Hành độngRequest field (ráp DTO)
R0「完了」/「一部未受取のまま完了」ボタンNút gửi → gọi POSTtrigger POST .../complete
R1受取チェックボックス（行）Tích từng kiện đã nhậnreceivedItemIds: number[] ⇐ gom items[].id đã tích
R2「連絡済み」チェック / 「ESへ電話する」Check B.4 hoặc bấm gọi B.5esKitchenContacted: boolean (bắt buộc true nếu nhận một phần)

Request body ví dụ

POST /driver/receipts/9001/complete

{
  "receivedItemIds": [70011, 70012, 70021],   // ⇐ R1 (các kiện đã tích)
  "esKitchenContacted": true                          // ⇐ R2 (đã liên lạc ES)
}
Phân nhánh hoàn thành: tất cả kiện đã tích ⇒ FULL (bỏ qua esKitchenContacted, toast → Home) · còn kiện chưa tích ⇒ hiện Modal B ⇒ cần esKitchenContacted=true ⇒ PARTIAL. 0 kiện tích ⇒ nút 完了 disabled (không gọi API).

FIELD LEGEND

API: Tab B data is populated via GET /driver/delivery-list?tab=ES_DELIVERY&startDate=...&endDate=...
Shows ES配送便 shipments chưa xong (deliveryStatus IN UNDELIVERED, TROUBLE). Filter「ステータス」= deliveryStatus.
Shows shipments with status「未配送」or「トラブル」(COOL便 + ES配送便).

Admin Order — 注文管理 (E03)

Mockup tương tác + đặc tả API cho System Admin quản lý đơn: đơn món (注文) — trả lời納期 / xuất hàng / thông báo — và đơn vật tư・発注 NCC (仮 → 確定 → 送信).

⚠️
Cảnh báo implementation (quan trọng): phần lớn luồng này ❌ chưa implement trong es-kitchen-api. Code thật chỉ có GET /admin/orders + POST …/:id/refund ✅ nhưng đó là đơn mua có payment (concept khác — không có status納期/出荷, không field shipping). Material order và Supplier order (発注) chưa có entity/controller/migration. Mỗi trang ghi rõ trạng thái từng endpoint; phần 🟡 tham chiếu DESIGN.md §5.3/5.4/5.5 (đề xuất).

2 · Convention API — bám sát Phase 1 (BẮT BUỘC)

⚠️
Routing: App di động = UserModule được RouterModule.register() với prefix '' → full path = đúng path khai trong @Controller(). Hầu hết controller dùng prefix user/... (vd GET /user/menu/products, GET /user/favorites). Riêng feedback dùng POST /contact (không có user/).

Response envelope

{
  "statusCode": "success",
  "message": "Request successful",
  "data": <payload>
}
// Controller return data thô; envelope
// tự bọc ở interceptor. Lỗi validate:
// { statusCode:"validaton_error", ... }

List / pagination

// Query (BaseSearchRequest):
?page=1&limit=10&q=&order=DESC&orderBy=createdAt

// data:
{ "items":[...], "total":100,
  "page":1, "limit":10, "totalPages":10 }

Bấm vào màn để mở

UE-1E01 My Page · Allergen Settings Trang cá nhân → cài đặt dị ứng (toggle, lưu) → demo cảnh báo khi thêm giỏ. Có luồng Onboarding lần đầu. PUT /user/allergens/me UE-2E01 Menu · Allergen Filter Danh sách món + bottom-sheet chọn chất dị ứng. Chế độ ẩn/cảnh báo, badge tồn kho. GET /user/menu/products UE-3E01 Product Detail · Reviews Chi tiết món + tab 詳細/レビュー hiển thị đánh giá công khai cùng công ty + giỏ hàng sticky. GET /user/menu/products/:id/reviews UE-4E01 Order History · Review & Feedback Chi tiết đơn COMPLETED → chấm sao + tags từng món; ô bình luận = góp ý dịch vụ (→ /contact). POST /user/orders/:id/reviews UE-5E01 Survey from Admin Thông báo khảo sát → form câu hỏi (single/multi/free-text), khoá khi hết hạn. POST /user/surveys/:id/responses UE-6E01 Next-month Wishlist Danh sách ≤15 món tháng sau · chấm thang 3 bậc · deadline · trạng thái đã gửi. POST /user/wishlist-campaigns/:id/votes

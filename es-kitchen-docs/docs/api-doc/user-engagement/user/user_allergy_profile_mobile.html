UE-1 · API仕様 — Allergen Settings & Feedback

① Master danh mục dị ứng

GET /user/allergens REUSE P1JwtAuthGuard

KHÔNG query/param. Trả mảng allergen sort ASC — render lưới 2 nhóm.

fieldtypenote
idstringbigint→string
namestringtên (JP)
imageUrlstring|nullicon
sortnumberthứ tự
allergenTypeenumspecified | quasi_specified

② Dị ứng đã lưu của tôi (cá nhân hoá)

GET /user/allergens/me NEWJwtAuthGuard
PUT /user/allergens/me NEWJwtAuthGuard · @BlockGuest
// GET /user/allergens/me — KHÔNG query/param
// → trả lựa chọn hiện tại của user

// PUT body — ghi đè TOÀN BỘ lựa chọn (replace-all)
{ "allergenIds": ["4"] }     // chỉ 小麦

// response (cả GET & PUT)
{ "allergenIds": ["4"],
  "allergens": [ { "id":"4","name":"小麦","allergenType":"specified" } ] }

Lưu qua bảng trung gian user_allergens(user_id, allergen_id) — FK sang allergens. PUT = replace-all (xóa cũ, insert mới trong 1 transaction). Đây là dữ liệu dùng cho cảnh báo khi thêm giỏ (mục ④).

ℹ️
Onboarding tutorial slides không có API — app tự lưu cờ đã-xem ở local storage.

③ Feedback dịch vụ (ご意見)

POST /contact REUSE P1OptionalJwtAuthGuard
// body
{ "email": "eskitchen@example.jp",  // bắt buộc, hợp lệ
  "description": "ご意見の内容…" }    // bắt buộc
// data: "Your request has been sent successfully."

Có token → BE ghi user_id. Admin (E03) có trang xem danh sách feedback & trả lời qua email.

④ Cảnh báo dị ứng khi thêm giỏ (client-side)

POST /user/cart/items REUSE P1JwtAuthGuard
// Request body (AddToCartRequest)
{ "productId": "55",        // string, bắt buộc
  "quantity": 1,            // int ≥1, bắt buộc
  "companyCode": "CU00001" } // string, optional
// Response (CartResponse)
{ "id":"7", "totalItems":3, "totalPrice":300,
  "items":[ { "id":"21","productId":"55","name":"…",
    "price":100,"quantity":1,"images":["…"] } ] }

Không có API riêng cho cảnh báo. FE đối chiếu productDetail.allergens[].id với allergenIds (GET /user/allergens/me); nếu trùng → hiện dialog アレルゲンにご注意ください; user xác nhận mới gọi POST /user/cart/items.

UE-3 · API仕様 — Detail & Reviews

① Chi tiết món (tab 詳細)

GET /user/menu/products/:id REUSE P1JwtAuthGuard

ProductDetailResponse: name, price, description, energyValue, productTags, isFavorite, cartQuantity, isInCurrentMenu, allergens[], allergensOptional[] (+ nhiều field dinh dưỡng). Có sẵn allergens[] → dùng cho cả tab chi tiết & đối chiếu dị ứng.

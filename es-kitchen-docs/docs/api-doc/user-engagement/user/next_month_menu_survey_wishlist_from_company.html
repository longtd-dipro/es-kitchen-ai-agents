UE-6 · API仕様 — Wishlist Campaign (Company → User)

① Chiến dịch đang mở của công ty tôi

GET /user/wishlist-campaigns/active NEWJwtAuthGuard 
// Request: KHÔNG param (lấy campaign OPEN của company user)
// Response
{
  "id":"9", "title":"来月食べたいメニュー",
  "targetYearMonth":"2026-02",
  "openAt":"2026-01-20T00:00:00Z",
  "closeAt":"2026-01-30T14:59:00Z",
  "status":"OPEN",            // OPEN | CLOSED
  "alreadyVoted": false,
  "items": [                  // ≤15, do E02 chọn
    { "productId":"34","name":"ビーフカレー",
      "images":["…"], "myScore": 2 }
  ]
}

Vào màn từ thông báo loại WISHLIST_CAMPAIGN (body.campaignId) hoặc gọi thẳng /active. myScore = điểm user đã chấm (nếu có).

② Gửi bình chọn (thang 3 bậc)

POST /user/wishlist-campaigns/:id/votes NEWJwtAuthGuard · @BlockGuest 
// Request body
{ "votes": [
    { "productId":"34", "score":2 },
    { "productId":"56", "score":3 }
] }
// score ∈ {1,2,3} · 1=気になる 2=好き 3=大好き
// Response
{ "saved": 2 }
rule chi tiết
thời hạn openAt ≤ now ≤ closeAt, ngoài hạn → 423 Locked
tối đa ≤ số items của campaign (≤15)
score int 1–3 (khoá cứng)
unique (campaign_id, user_id, product_id) — replace khi gửi lại

Bảng mới: wishlist_campaigns(company_id, target_year_month, open_at, close_at, status, created_by) · wishlist_campaign_items(campaign_id, product_id) · wishlist_votes(campaign_id, user_id, product_id, score). Không dùng lại user_favorites (chỉ là tim nhị phân, không có campaign/score).

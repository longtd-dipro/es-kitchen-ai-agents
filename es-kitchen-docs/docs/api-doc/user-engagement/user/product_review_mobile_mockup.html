UE-4 · API仕様 — Review & Feedback

① Chi tiết đơn (xác định quyền đánh giá)

GET /user/orders/:id REUSE P1JwtAuthGuard

OrderResponse: orderNumber, status, total, paymentMethod, orderDetails[{productId, productName, price, quantity}], payment. Mở review khi status=COMPLETED. P2 thêm cờ reviewed mỗi orderDetail để ẩn món đã chấm.

② Gửi đánh giá sản phẩm

POST /user/orders/:orderId/reviews NEWJwtAuthGuard · @BlockGuest
// body — mảng review theo từng món của đơn
{ "reviews": [
    { "productId":"12", "rating":2,
      "comment":"味が濃い", "tags":["味が合わない","味が濃い"] },
    { "productId":"34", "rating":5,
      "comment":"", "tags":["美味しい","コスパが良い","ご飯に合う"] }
] }
// data → { "created": 2 }
fieldrule
productIdphải thuộc orderDetails của đơn
ratingint 1–5, bắt buộc
commentstring ≤100, optional
tagsstring[] (chip lý do), optional

Rule: order.status=COMPLETED & order.user=current; unique (order_id, product_id, user_id) — mỗi đơn/món chấm 1 lần. Bảng mới:

product_reviews (
  id, product_id FK, user_id FK, company_id FK,
  order_id FK, rating int, comment varchar(100),
  tags simple-array, created_at )

③ Ý kiến tự do (ご意見)

POST /contact REUSE P1OptionalJwtAuthGuard
{ "email":"eskitchen@example.jp", "description":"ご意見…" }

Chỉ gọi khi ô ご意見 có nội dung. Admin (E03) đọc & trả lời qua email.

UE-2 · API仕様 — Menu & Allergen Filter

① Danh sách món + lọc dị ứng

GET /user/menu/products EXTEND P1JwtAuthGuard
// query (Phase 1 + P2 thêm)
?keyword=&category=惣菜
&allergenFilterMode=warn   // P2: off | hide | warn
field (mỗi product)typenote
idstring—
namestring—
imagesstring[]—
energyValue/baseAmount/baseUnitnum/strkcal hiển thị
productTagsenum[]NEW · 短賞味期限
isFavoritebooleantim đỏ
sellingPricenumberEXTEND — từ menu_products.selling_price (list P1 chưa expose)
allergensAllergen[]EXTEND — để FE đối chiếu
allergenWarningbooleanEXTEND — true nếu giao với allergen user (mode=warn)
stockStateenumEXTEND — IN_STOCK·LOW·OUT_THIS_MONTH·OUT_LAST_MONTH

Response cũng có categories[] (tabs) & activeYearMonths[]. mode=hide → BE loại bỏ món trùng allergen; OUT_LAST_MONTH luôn bị ẩn (§5.2).

② Master + lựa chọn của user (cho sheet)

GET /user/allergens REUSE P1JwtAuthGuard
GET /user/allergens/me NEWJwtAuthGuard

Sheet pre-check theo allergenIds[] đã lưu (xem UE-1). Đổi lựa chọn ở đây có thể chỉ là filter tạm thời của phiên (không bắt buộc PUT).

③ Toggle yêu thích

POST /user/favorites/:productId REUSE P1JwtAuthGuard · @BlockGuest

UE-5 · API仕様 — Survey (Admin → User)

① Thông báo khảo sát

GET /user/notifications/:id REUSE P1JwtAuthGuard
// NotificationDetailResponse (type=SURVEY)
{ "id":"701", "title":"…アンケートのお願い",
  "content":"…", "type":"SURVEY",
  "body": { "surveyId":"55" },   // P2: gắn surveyId
  "isRead":true, "createdAt":"…" }

P2 thêm SURVEY vào NotificationType & surveyId vào NotificationBody.

② Lấy nội dung khảo sát

GET /user/surveys/:id NEWJwtAuthGuard
{
  "id":"55", "title":"サービス満足度アンケート",
  "description":"…",
  "openAt":"2026-02-16T00:00:00Z",
  "closeAt":"2026-02-28T14:59:00Z",
  "status":"OPEN",            // OPEN | CLOSED
  "alreadyAnswered": false,
  "questions": [
    { "id":"1","order":1,"type":"SINGLE_CHOICE",
      "text":"料理の味は？","required":true,
      "options":[{"id":"o1","label":"とても満足"}, …] },
    { "id":"2","order":2,"type":"MULTI_CHOICE", … },
    { "id":"3","order":3,"type":"FREE_TEXT",
      "maxLength":256,"required":false }
  ]
}
question.typeUI
SINGLE_CHOICEradio
MULTI_CHOICEcheckbox
FREE_TEXTtextarea (maxLength)

③ Gửi câu trả lời

POST /user/surveys/:id/responses NEWJwtAuthGuard · @BlockGuest
{ "answers": [
    { "questionId":"1", "optionIds":["o2"] },
    { "questionId":"2", "optionIds":["o1","o2"] },
    { "questionId":"3", "freeText":"…" }
] }

Rule: chỉ user thuộc company đích & openAt ≤ now ≤ closeAt; mỗi user 1 lần (409 nếu đã trả lời). Bảng mới: surveys, survey_questions, survey_distributions(company), survey_responses, survey_answers.

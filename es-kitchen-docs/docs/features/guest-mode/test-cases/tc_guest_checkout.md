# TC: Thanh Toán Guest (US-03)

> **Module:** Guest Checkout — nhập Company ID, validate, thanh toán
> **Scope:** Mobile App E01 + API (indirect)
> **Related US:** US-03
> **Related BR:** BR-03, BR-04, BR-05, BR-09

## Fields phân tích trước khi sinh TC

**Form: Nhập Company ID**
- Field: `Company ID` — kiểu Text
- Validation: required, phải tồn tại trong hệ thống, không lưu giữa các lần checkout

## Bootstrap — `main.dart`

```dart
void main() => mainCommon(AppFlavor.production);   // flavor/main_*.dart gọi mainCommon(AppFlavor.x)

void mainCommon(AppFlavor flavor) async {
  WidgetsFlutterBinding.ensureInitialized();
  await dotenv.load(fileName: ".env");
  await FunctionExt.clearCacheOnStartup();
  final sharedPrefs = await SharedPreferences.getInstance();

  final container = ProviderContainer(overrides: [
    sharedPrefsProvider.overrideWithValue(sharedPrefs),
  ]);

  final fcmService = container.read(fcmServiceProvider);
  await fcmService.init();
  await fcmService.requestPermission();
  container.read(fcmControllerProvider);
  await container.read(deepLinkServiceProvider).init();

  SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp]);
  runApp(UncontrolledProviderScope(container: container, child: const MyApp()));
}
```

**Flavor entry:** `lib/flavor/main_development.dart` · `main_staging.dart` · `main_production.dart` — mỗi flavor gọi `mainCommon(AppFlavor.<x>)`. `AppFlavor.envFileName` map `.env` / `.env.stg` / `.env.prod`, nhưng `main.dart` hiện vẫn `dotenv.load(fileName: ".env")` cố định (chưa dùng `envFileName`).

## Env — flutter_dotenv

File `.env` (khai báo trong `pubspec.yaml` assets; không đọc giá trị theo policy). Code trong `lib/` **chỉ tham chiếu `BASE_URL` và `SOCKET_URL`** qua `dotenv.env[...]`; các key còn lại là cấu hình build/CI, **chưa verify được** từ code:

| Key | Purpose |
|---|---|
| `APP_NAME` | App display name |
| `BUNDLE_IOS_ID` | iOS bundle ID |
| `BUNDLE_ANDROID_ID` | Android package name |
| `PROVISIONING_IOS` | iOS provisioning profile |
| `APPLE_TEAM_ID` | Apple developer team |
| `BASE_URL` | REST API base URL |
| `SOCKET_URL` | Socket.io endpoint |
| `DEPLOYGATE_API_KEY` | DeployGate CI |
| `DEPLOYGATE_USER` | DeployGate user |
| `EMAIL_STORE` | Contact email |

**Không hard-code URL** — luôn qua `dotenv.env[...]`.

# 住所検索：郵便番号データの取り込み手順

決定：台帳 S「住所検索のデータの出どころ」（#429）・台帳 AA（#583）。全サイトの「住所検索」ボタンが使う。

## 決まり

- データは日本郵便が公開している郵便番号データ（無料）の **`utf_ken_all.csv`**（住所の郵便番号・UTF-8）。
- **データベース（`zip_codes` 表）に取り込む**。リポジトリには大きなデータを置かない（`data/` は git に入れない）。
- 更新は**必要なときに手で取り込み直す**（日本郵便は月1回ほど更新。自動更新は後）。取り込みは入れ替え。
- 1つの郵便番号に複数の住所があるときは**最初の1件**。町域が「以下に掲載がない場合」「…一円」「…の次に番地がくる場合」のときは町域を空にし、（）の中は外す。番地・建物は手で入れる。
- 事業所の個別郵便番号・私書箱などの特別な郵便番号は対象外（`utf_ken_all.csv` だけを使う）。

## 手順

1. 日本郵便の「郵便番号データダウンロード」から「住所の郵便番号（全国一括）UTF-8形式」を落として解凍し、`utf_ken_all.csv` を取り出す。
2. 次のどちらか。
   - `data/utf_ken_all.csv` に置いて `npm run db:reset` で DB を作り直す（DB を開いたとき、表が空なら自動で取り込む）。
   - いまの DB に入れる：`npm run zip:import -- <utf_ken_all.csv のパス>`（環境変数 `ES_ZIP_CSV` でも指定できる）。
3. 画面の「住所検索」で確認する（例：1000005 → 東京都 千代田区 丸の内）。

## 取り込み前の動き

表が空（まだ取り込んでいない）ときは、画面は**見本の数件**（`lib/ui/zip.ts` の `ZIP_DEMO`）で動く。取り込み済みで見つからない郵便番号は「該当する住所がありません」。

## 部品

`lib/server/zip.ts`（取り込み・検索）、`app/api/zip/[zip]/route.ts`（`GET /api/zip/<7桁>`）、`lib/ui/zip.ts` の `lookupZipAsync`（画面から呼ぶ）、`scripts/import-zip.mjs`。

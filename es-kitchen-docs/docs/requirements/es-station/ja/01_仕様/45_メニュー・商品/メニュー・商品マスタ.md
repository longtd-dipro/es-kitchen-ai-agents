## 1. 月間メニュー

### 1-1. 単位・コース・PDF

| # | 決まり | 根拠 |
|---|---|---|
| 1-1 | **メニューは1ヶ月（サイクル月）に1つ。** コース・温度帯で分けない | RD-MN-001、台帳 F |
| 1-2 | お客様に見せる商品は、**商品のコース**（ライト＝冷蔵・常温／スタンダード＝冷凍も）・**契約のピッキング倉庫**・**自販機の機種（コラム）**で絞る | RD-MN-003、台帳 M-2 |
| 1-3 | **メニュー PDF は2つ**：① ライト用（冷蔵のみ）② スタンダード用（1ページ目 冷蔵・2ページ目 冷凍）。ライトのお客様にはスタンダード用を見せない。PDF は 5MB まで | RD-MN-005・006・030、台帳 F |
| 1-4 | 品数の目安（ライト30〜40 など）・過去3か月の重複の警告は**システムに入れない** | 台帳 F |

| 2-12 | 削除できる。削除したあと、同じ年月でもう一度作れる | RD-MN-051 |

### 1-3. 公開

| # | 決まり | 根拠 |
|---|---|---|
| 3-1 | 公開ステータス：**非公開／公開／自動公開**（＋削除済）。**法人向け**の公開（従業員向けの公開は持たない）。保存の既定は非公開 | RD-MN-027・028・030 |
| 3-2 | 公開の条件：**全商品が「公開可能」・メニュー PDF あり・その月の仮発注が承認済み**。条件が足りないまま公開する手段はない | 台帳 M-2 |
| 3-3 | 「公開可能」は運営が商品ごとに付けるチェック。まとめて付ける「全商品を公開可能にする」あり | RD-MN-038 |
| 3-4 | 自動公開：日付を決めて予約し、その日に条件がそろっていれば公開する。**3日前から、条件が足りないメニューを運営の TOP に警告**（毎日。通知は増やさない） | RD-MN-031・033、台帳 F・M-2 |
| 3-5 | 早めに手で公開する・自動公開にするときは確認を出す | RD-MN-034 |
| 3-6 | 公開したら**法人へ**知らせる。公開のあとで直したときは、チェックを入れたときだけ知らせる。アプリのユーザーへの知らせは商品が届いたとき（台帳 M-2） | 台帳 M-2 |
| 3-7 | D7 の翌日に、運営の一覧の状態を「終了」にする（お客様・アプリの表示には使わない） | 台帳 E |

### 1-4. 基準注文数（標準数）

| # | 決まり | 根拠 |
|---|---|---|
| 4-1 | 最大注文数は持たない。**基準注文数だけ**。月ごとにメニューが持つ | RD-MN-040、台帳 M-2 |
| 4-2 | **3種類**：通常（ライト・スタンダード）／短消費期限なし／自販機（ライト〈自販機〉）。どれも **50プランの代表値**。ほかのプランは食数の比で直す | RD-MN-041、台帳 F |
| 4-3 | 短消費期限の商品は「短消費期限なし」に、自販機に置けない商品は「自販機」に **0 を自動で入れる**（手で直せる） | RD-MN-042 |
| 4-4 | **種類ごとに合計＝50 でないと保存できない。** 1つ直すと、手で直していない欄が自動で動く（CSV も同じ） | 台帳 M-2 |
| 4-5 | システムが提案する：① 直近2〜3ヶ月の注文の割合（新商品は同じカテゴリの平均）→ ② **平均仕入単価（50プラン）が目標の幅に入るように調整**（いちばん安い商品を増やし、高い商品から減らす。手で直した商品は動かさない・どの商品も1未満にしない・届かなければ警告・「↑n／↓n」の印と「調整を戻す」） | 台帳 F |
| 4-6 | **平均単価の目標**は、メニュー作成の画面で**「下限〜上限」**を入れる（冷蔵庫・自販機それぞれ）。初期値は前月の値。公開したメニューは公開時の値で固定。設定管理の専用画面はなくす | 台帳 F |
| 4-7 | 対象外の商品・カテゴリを指定できる。自販機は枠ごと・機種ごと（`50_注文/注文.md` §6） | 台帳 H |

### 1-5. 営業サンプルの枠

- メニュー作成の画面に商品ごとの「営業サンプル」のチェックと、**その月の営業サンプルの件数**（既定は月60件＝15件×4。足せる。メニューの公開〈締切〉まで直せる）（RD-MN-044・045）。詳しくは `75_営業サンプル/営業サンプル.md`。

## 2. 商品マスタ

| # | 決まり | 根拠 |

| 8-18 | 同梱資材・出荷時の特殊指示：残す。出荷指示 CSV に出す。資材の在庫は引かない | 台帳 F |

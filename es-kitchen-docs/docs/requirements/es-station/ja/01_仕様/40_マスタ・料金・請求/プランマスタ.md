## 1. 確定済みの3つの決定（読み直さない）

| # | 決定 | 意味 |
|---|---|---|
| 1 | **価格はコースごとに直接持つ** | 「スタンダード価格＋ライト値引き」では持たない。ライトも世代ごとに自分の価格を持つ（台帳 E「料金世代」＝A、F「プランの価格の持ち方」） |
| 2 | **プランは 機種ID・台数・パターン だけを持つ** | 機種の名前・容量・価格・最低利用期間は機種マスタが持つ。プランにはコピーしない（台帳 F「標準貸出設備」、28-182） |

## 2. 役割と範囲

- プランマスタは、プラン（月次提供上限の食数ごとの契約の型）の **価格・提供数の上限下限・標準の配送回数・標準貸出設備・企業負担額・免責金額** を一元で持つ運営Web のマスタ。
- 1つのプランに、コースごとのタブを持つ。契約（子契約）は **プランID＋コース＋適用された価格プラン（価格世代）** で持つ（28-181）。
- 持たないもの：機種の情報と価格（→機種マスタ）、オプション・値引き（→オプション・値引きマスタ）、配送・契約オプション（→契約ごとのオプション）、資材の単価（→資材マスタ）、自販機の初期費用・リース料（→オプション OP000008・OP000037。プランの「初期料金」は廃止）、冷凍の割合（持たない：28-155）。
- 紹介フィーのプラン（代理店）は別マスタ（`70_代理店/`）。

## 4. プランの共通項目

| 項目 | 内容 |
|---|---|
| プランID | ES＋6桁（例 ES000004）。採番後は変更しない |
| 公開用プラン名 / 管理用プラン名 | 各最大60文字。公開用は法人Webと請求書、管理用は社内・一覧・検索。公開用を入れたとき管理用が空なら同じ値を入れる |
| 公開ステータス | 公開／非公開。非公開は法人Webの申込・プラン変更に出さない。契約中の拠点には影響しない。削除は論理削除。**価格世代の「公開用」とは別のもの**（こちらはプラン自体の公開） |
| 月次提供上限の合計 | 食数（例 100プラン＝100）。0以上の整数・最大 9,999 |
| 企業負担額（税込・1食） | 既定 100円。プラン料金に含まれる額（追加で請求しない）。子契約の初期値になる |
| 企業負担分の税率 / 基本料金の税率 | 税率マスタから選ぶ。既定 8% / 10% |
| 免責金額（tolerance） | 在庫差額の許容範囲（円）。超えた分を実績精算で請求する。**プラン＋コースごとに持つ**（2026-10-12 hong 回答。旧：プラン単位で1つ） |
| 基本比×倍 | オーダーの標準数への倍率。一覧には出さない |
| 利用人数目安 | 例 14名。**主な用途は、お客様へプランをおすすめ（サジェスト）するための目安**（2026-10-12 hong 回答）。請求・判定には使わない。おすすめの出し方の細かい点は14章 |
| コース | 3章のとおり複数選択 |

## 5. 提供数の上限・下限と配送回数（コースごと）

| 項目 | ESスタンダード | ESライト（冷蔵庫／自販機） |
|---|---|---|
| 冷凍_月次提供数 上限／下限 | あり。下限 ≦ 上限 | なし |
| 冷蔵・常温_月次提供数 上限／下限 | あり。下限 ≦ 上限 | あり。**上限＝月次提供上限の合計**（違うと保存できない） |
| 上限の合計のチェック | 冷凍の上限＋冷蔵・常温の上限 **≧** 月次提供上限の合計（＝ではない） | 上記のとおり |
| 標準の配送回数（冷蔵・常温） | 1回以上／月。温度帯ごと | 同左 |
| 標準の配送回数（冷凍） | 1回以上／月。**初期値は全プラン1回** | なし |

- 標準の配送回数の例（冷蔵庫の表）：ES50＝1回／ES100〜600＝2回／ES650以上＝4回。契約の配送回数が標準を超えた分に、配送回数追加（OP000001）が付く（温度帯ごと・相殺しない）。
- 1回の納品数＝上限 ÷ 標準の配送回数（切り上げ）。機種のサイズ判定に使う（自動算出・入力しない）。
- 1商品あたりの上限は持たない。

## 6. 残りわずか率

- 個人アプリの「残りわずか」バッジの判定率。**初期値 25%**。
- **プラン＋コースごとに運営がマスタ画面で設定**する（コード内の固定値にしない）。
- しきい値＝切り捨て（拠点の実際の注文数 × 率）。理論在庫 ≦ しきい値 かつ しきい値 ≧ 1 のとき表示。「プランが100以下」のルールは廃止。
- 注意：この「切り捨て」は注文数からしきい値を出す箇所だけ。金額の端数（8章）は四捨五入。

## 7. 価格（コースごとに直接持つ・複数世代）

### 7.1 持ち方

- 価格は **コースのタブの中の「価格プラン」表**に、**1行＝1つの価格世代**で持つ。
- 1行の中身：公開用（選択中）／価格プランの名前（元の料金・改訂第一回目…。世代の名前はシステム全体で共通）／開始期間・終了期間／**価格（COOL便）／価格（ES配送便）**（税抜・1か月のプラン料金）／内訳（自動）。
- **スタンダードの価格を基準にライトを値引きする持ち方はしない。** 3コースとも、自分の価格をそのまま入力する。ライト→スタンダードの移行差額（値引き DC000021）は、同じ世代の価格の差として **算出するだけ**で、価格の持ち主ではない。
- ESライト（自販機）の価格は **ES配送便のみ**。**リース料は価格に含める**（OP000037 は廃止・2026-10-13 hong）。初期費用は価格に含めない（OP000008）。プランに含む標準の台の分は価格に入っていて、足した台だけ機種マスタの月額。
- 内訳（自動計算・入力しない）：企業負担分（税抜）と 基本料金＝価格 − 企業負担分（税抜）。基本料金が0円未満になる価格は保存できない。
- 開始期間・終了期間は **参考（記録）**。契約がどの世代を使うかは期間ではなく子契約の「適用された価格プラン」で決まる。期間は重ねない（行を足すと前の行の終了期間に前日が入る）。

### 7.2 選択中＝公開用（1つの値）

- **各コースに、公開用（＝選択中）の行がちょうど1つ**。0行・2行以上は保存できない。
- 法人Webの申込・プラン変更に出るのは、公開用の世代だけ。新しく作る子契約の初期の世代になる。
- 最新の世代が自動で公開用になることはない。運営が選ぶ。
- 新規の契約は申込のときの公開用の世代をそのまま使う（世代の適用開始が契約の開始より後でも。適用開始は参考）。古い価格を続けたいときは運営が公開用を切り替える日を選ぶ。先の月の子契約は前の月の世代を引き継ぐ〔台帳 AS #769・#780〕。
- 公開用にしない世代は、特定の法人向けの個別価格として使える（子契約で世代を選ぶ。法人には紐づけない）。
- `選択中` と `公開用` を、別の項目・別のフラグ・別の画面表示として持たない。

### 7.3 既存契約への影響

- **新しい世代を足しても、既存の子契約の価格は変わらない。** 子契約は「適用された価格プラン」を自分で持ち、作ったときの世代のまま。
- 世代の切り替えはプランマスタでは行わない。**契約の側（子契約一覧の一括変更）から**、プラン・コース・価格世代で絞り、適用開始サイクルを指定して、未確定の子契約にだけ当てる（確定・請求済の月は変えない）。事前告知はお知らせ配信で運営が手で行う。
- 使っている世代の価格を直すのは「誤りの訂正」として扱い、履歴に残す。使っていない世代だけ削除できる。

## 8. 企業負担分（税抜）の計算

```
企業負担分（税抜）
= 企業負担額（税込・1食）
× 月次提供上限の合計
÷（1 + 企業負担分の税率）
```

- **1円未満は四捨五入**（切り捨てない）。台帳 E「税込から税抜を出すときの端数＝四捨五入」と同じ。
- 基本料金（税抜）＝ 価格（税抜）− 企業負担分（税抜）。
- 例：企業負担額100円・月次提供上限100・税率8% → 100 × 100 ÷ 1.08 ＝ 9,259.259… → **9,259円**。価格 49,500円なら 基本料金 40,241円。
- 請求書は、子契約の「福利厚生の適用」が ON で2行（基本料金10%／企業負担分8%）、OFF で1行にまとめる。費目（①）は常に2行で、金額と税は変わらない。

## 9. 標準貸出設備（機種ID・台数・パターンだけ）

- プランが持つのは **機種ID・台数・パターン（標準／代替）・備考** だけ。
- **機種名・容量・価格・最低利用期間は機種マスタから参照する。プランにコピーしない。** 機種マスタを変えても、すでに作った契約には影響しない（契約は設定時点の値を持つ）。
- ここに載っている機種・台数が「プランに含まれる設備」＝初期料金・月額料金とも無料。無料かどうかの判定を機種マスタ側に持たない。機種マスタには「標準で含むプラン」を持たない（プランマスタの標準貸出設備で見る）。
- パターン：標準／代替。同じパターンの行を1つの構成として扱う（代替は申込で標準の代わりに選べる構成）。
- 「相談して決める」＝する の場合、法人Webは標準構成を表示するだけで、変更は相談。
- 初期備品・プランに含む資材（資材 × コースの数量・月の無料数量）は、プランマスタ詳細のカードで入力する。資材の情報は資材マスタ。

## 10. CSV

- 入口は **プランマスタ一覧の「CSV取込」1つだけ**。1つのファイルに プラン／コース／価格／設備 の行を入れる（28-183）。設備の行だけのファイルも同じ入口。専用の設備CSVボタンは置かない。
- 設備の行の列：プランID・コース・パターン・機種ID・台数・備考。プランID＋コースごとに、CSV の行で置き換える。
- CSV の金額は数字だけ（`1000`、「円」を付けない）。空欄＝更新時は変えない、消すときは `-`。最大5,000行。
- エラーの行は取り込まず、行番号とエラー内容を出す（エラー一覧CSVを出せる）。
- 価格世代の行は、取込で削除できる（28-183 の形）。それ以外は CSV で削除しない。
- CSV出力と取込は、画面と同じ項目・同じ検証。CSV取込の変更履歴は「CSV取込」として残す。

## 11. 権限・履歴・検証

**権限**（`運営Web_権限表_20261003.md`）：「プラン管理」は フル権限＝CRUD、ほかの役割＝R。システム管理（権限付与を編集できる役割）も CRUD。

**変更履歴**：変更日時・変更内容（項目名「変更前」→「変更後」）・変更者・変更区分（手入力／CSV取込）。価格世代の追加・訂正・公開用の切替も残す。

**検証（保存時）**

1. 公開用の行がコースごとにちょうど1つ。
2. ライト：冷蔵・常温の上限＝月次提供上限の合計。スタンダード：冷凍上限＋冷蔵・常温上限 ≧ 合計。
3. 下限 ≦ 上限（冷凍・冷蔵・常温それぞれ）。
4. 標準の配送回数は1以上の整数。
5. 基本料金（価格 − 企業負担分）が0円未満になる価格は保存できない。
6. 価格世代の期間が重ならない。
7. 自販機コース：設備に自販機の行が1つ以上、冷蔵庫・冷凍庫の行がない。自販機コースの配送方法は ES配送便のみ。
8. 設備の機種IDが機種マスタに存在する。台数は1以上の整数（最大99）。
9. 使用中（契約あり）のプランは削除できない（非公開にする）。使用中の価格世代は削除できず、訂正だけ。

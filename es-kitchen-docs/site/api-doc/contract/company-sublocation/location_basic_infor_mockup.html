{ } API仕様 — 基本情報 (E02)

Endpoints — Self (công ty đang đăng nhập · S2/S3)

GET /company-admin/company/basic-info AdminCompanyGuard
PATCH /company-admin/company/basic-info AdminCompanyGuard

Endpoints — Sub-company (công ty con · G3/G4)

GET /company-admin/company/sub-companies/:id AdminCompanyGuard
PATCH /company-admin/company/sub-companies/:id/basic-info AdminCompanyGuard

Self & sub-company dùng cùng layout. Sub khác ở chỗ :id trong path (phải thuộc subtree của công ty đang đăng nhập).

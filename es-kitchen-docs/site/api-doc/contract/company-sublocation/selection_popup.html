{ } API仕様 — マスタ選択 (E02)

Endpoints

GET /company-admin/company/masters/deliverers AdminCompanyGuard
GET /company-admin/company/masters/relays AdminCompanyGuard

E03 tương đương dưới /admin/masters/* (cùng entity master). E02 chỉ thấy bản ghi status=active.

Query (extends BaseSearchRequest)

{
  "page": 1,          // number · optional · default 1
  "limit": 10,        // number · optional · default 10
  "q": "虹の橋",      // string · optional · keyword
  "prefecture": "愛知県"   // string · optional · lọc theo 都道府県
}

Interaction

ActionAPI?
Mở popup / đổi filter / phân trang✅ GET masters/*
Chọn radio (single-select)❌ FE state
追加する❌ chỉ set 1 id vào field form cha (outsourcedDelivererMasterId / relayMasterId)

Note

Single-select → trả về 1 id set vào field hợp đồng. 追加する = không gọi API (chỉ FE state). Hai master còn lại cũng tồn tại nhưng là dropdown đơn giản: carriers (M4 · carrier_integration_configs) và plans (M1 · plan_masters).

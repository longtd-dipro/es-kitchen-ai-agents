    TC: Liên Kết Email — Upgrade Guest (US-04)

    Module: Link Email / Upgrade Guest to Full Account
    Scope: Mobile App E01 + API (indirect)
    Related US: US-04
    Related BR: BR-06, BR-07, BR-11, BR-12
    Related AC: AC-04-1 đến AC-04-8

    Fields phân tích trước khi sinh TC

    Form 1: Nhập Email
    - Field: Email — kiểu Email
    - Validation: required, format email hợp lệ, chưa tồn tại dưới dạng full account

    Form 2: Nhập OTP
    - Field: OTP — kiểu Number, 4 chữ số (BR-12: crypto.randomInt(1000, 9999))
    - Validation: required, đúng 4 chữ số, còn trong thời hạn 5 phút

    Form 3: Set Password
    - Field: Password — kiểu Password
    - Field: Confirm Password — kiểu Password
    - Validation: required, min length (theo business rule), khớp nhau

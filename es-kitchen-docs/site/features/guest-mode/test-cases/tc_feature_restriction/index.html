    Related US: US-02
    Related BR: BR-10
    Related AC: AC-02-1, AC-02-2, AC-02-3, AC-02-4

    2. Quan sát danh sách orders    		 1. Màn Order History accessible (không bị redirect)

    GM_RESTRICT_TC_014 Feature Restriction BR-10 — Full account so sánh Medium Check user full account CÓ đủ 7 menu items mà guest bị ẩn Đã đăng nhập bằng tài khoản registered thường 1. Đăng nhập account registered
    2. Mở menu chính
    3. Kiểm tra 7 items: Thông báo, Yêu thích, Profile, Phương thức TT, Quản lý TK, Đăng xuất, Xóa TK    		 1. Tất cả 7 items đều hiển thị và accessible
    2. Xác nhận rằng việc ẩn items là chỉ dành cho guest    		 Account registered: qc_restrict_20260605@eskitchen.test / Test@12345 Medium
    GM_RESTRICT_TC_015 Feature Restriction BR-10 — Hidden không phải disabled High Check menu items bị ẩn với guest là hidden hoàn toàn (không phải disabled/greyed-out) Đã đăng nhập guest 1. Inspect UI tree của app (dùng Xcode Accessibility Inspector hoặc Android Layout Inspector)
    2. Tìm kiếm các element của 7 menu items bị restrict    		 1. Các element của 7 items không tồn tại trong UI tree
    2. Không có element visible=false hoặc opacity=0 che khuất item thật
    3. Không có element disabled mà vẫn render    		 — High

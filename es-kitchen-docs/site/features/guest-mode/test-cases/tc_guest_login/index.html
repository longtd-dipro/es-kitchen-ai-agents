    TC: Guest Login (US-01)

    Module: Guest Login — Màn hình Login, flow tạo guest account tự động
    Scope: Mobile App E01
    Related US: US-01
    Related BR: BR-01, BR-02, BR-08
    Related AC: AC-01-1, AC-01-2, AC-01-3, AC-01-4, AC-01-5, AC-01-6

    Bảng Test Cases

    ID Function Name Category Risk Level Test Scenario Precondition Steps Expected Results Test Data Priority
    GM_LOGIN_TC_001 Guest Login UI Visual — Login Screen Medium [UI Visual] Verify UI tổng thể màn hình Login App đã cài đặt, version hỗ trợ guest flow, người dùng chưa đăng nhập 1. Mở app
    2. Quan sát toàn bộ màn Login    		 1. Màn Login hiển thị đầy đủ các element: field Email, field Password, button Login, button "ゲストとして利用する"
    2. Button guest phân biệt rõ về mặt visual với button Login thường (khác màu hoặc khác style)
    3. Không bị vỡ layout trên iPhone 14 Pro (390x844) và Android mid-range (360x800)    		 Thiết bị: iPhone 14 Pro + 1 Android mid-range High
    GM_LOGIN_TC_002 Guest Login UI Visual — Guest Button Medium [UI Visual] Button "ゲストとして利用する" — trạng thái Normal App ở màn Login 1. Mở app
    2. Quan sát button "ゲストとして利用する"    		 1. Button hiển thị với label đúng "ゲストとして利用する"
    2. Button không bị ẩn (visible), không disabled
    3. Màu sắc, font, border-radius thống nhất với design system    		 — High
    GM_LOGIN_TC_003 Guest Login UI Visual — Guest Button Medium [UI Visual] Button "ゲストとして利用する" — trạng thái Loading khi đang gọi API App ở màn Login, network bình thường 1. Bấm button "ゲストとして利用する"
    2. Quan sát button trong khoảng 0–3 giây đang chờ API    		 1. Button hoặc màn hình hiển thị loading indicator (spinner/skeleton)
    2. Button bị disabled trong khi đang gọi API (không thể bấm double)
    3. Không có crash    		 — Medium
    GM_LOGIN_TC_004 Guest Login AC-01-1 — Button hiển thị High Check button "ゲストとして利用する" luôn hiển thị và không disabled trên màn Login App đã cài đặt version hỗ trợ guest flow 1. Mở app
    2. Kiểm tra sự tồn tại của button "ゲストとして利用する"    		 1. Button có mặt trên màn Login
    2. Button không bị ẩn (hidden = false)
    3. Button không ở trạng thái disabled    		 — Critical
    GM_LOGIN_TC_005 Guest Login AC-01-2 — Happy Path High Check đăng nhập guest thành công — không yêu cầu nhập thông tin, vào app trong ≤ 3 giây App ở màn Login, network tốt (4G/WiFi) 1. Bấm button "ゲストとして利用する"
    2. Đo thời gian từ lúc bấm đến khi màn hình chính hiện    		 1. App không hiển thị bất kỳ form nhập email/password nào
    2. Người dùng vào được app shell trong ≤ 3 giây
    3. Không xuất hiện badge/label "ゲスト" trên header
    4. App shell giống hệt user thường ngoại trừ các menu item bị ẩn (xem US-02)    		 Network: WiFi 20Mbps Critical
    GM_LOGIN_TC_006 Guest Login AC-01-3 — Token storage High Check token guest được lưu vào secure storage (không lưu plain text) App đã đăng nhập guest thành công 1. Đăng nhập guest
    2. Kiểm tra storage của app (iOS Keychain / Android Keystore) bằng debug tool    		 1. accessToken và refreshToken được lưu trong secure storage
    2. Token KHÔNG được lưu trong UserDefaults (iOS) hoặc SharedPreferences thường (Android)
    3. Format token giống với flow login thường (cùng cấu trúc JWT)    		 — High
    GM_LOGIN_TC_007 Guest Login AC-01-4 — API failure High Check xử lý khi API tạo guest thất bại App ở màn Login, server trả lỗi (500 hoặc network timeout) 1. Simulate lỗi API (block network hoặc mock server error)
    2. Bấm button "ゲストとして利用する"    		 1. App hiển thị error toast với message rõ ràng (ví dụ: "サービスに接続できません")
    2. Người dùng vẫn ở màn Login (không navigate đi)
    3. Không bị stuck / frozen screen
    4. Có thể thử lại bằng cách bấm button lần nữa    		 Server mock: trả HTTP 500 Critical
    GM_LOGIN_TC_008 Guest Login AC-01-4 — Network timeout High Check xử lý khi API tạo guest timeout App ở màn Login, network không ổn định 1. Tắt WiFi/data sau khi bấm button guest
    2. Chờ timeout    		 1. Sau timeout (~30 giây hoặc config timeout của app), hiển thị error toast
    2. Người dùng vẫn ở màn Login
    3. Không crash    		 — High
    GM_LOGIN_TC_009 Guest Login AC-01-5 — Re-open app, session valid High Check re-open app tái dùng guest session cũ khi token còn valid Đã đăng nhập guest, secure storage còn data, token chưa hết hạn 1. Đăng nhập guest lần đầu, ghi lại userId/email của guest
    2. Tắt app (không xóa data)
    3. Mở lại app    		 1. App đọc token từ secure storage
    2. App gọi API verify token
    3. Nếu token còn valid → vào thẳng app shell với cùng guest session (cùng userId, không tạo guest mới)
    4. Không hiển thị màn Login    		 Token lifetime: chưa hết hạn High
    GM_LOGIN_TC_010 Guest Login AC-01-5 — Re-open app, token invalid High Check re-open app tạo guest mới khi token đã hết hạn / invalid Đã đăng nhập guest, token đã hết hạn hoặc bị revoke 1. Force expire token (mock hoặc đợi token hết hạn)
    2. Tắt app
    3. Mở lại app    		 1. App verify token → nhận lỗi unauthorized
    2. App tự động gọi POST /auth/guest tạo guest mới
    3. Guest mới có userId và email khác với guest cũ
    4. Vào được app shell bình thường    		 Token: hết hạn hoặc bị revoke High
    GM_LOGIN_TC_011 Guest Login AC-01-6 — Xóa app + cài lại High Check xóa app rồi cài lại luôn tạo guest mới Đã đăng nhập guest lần đầu, ghi lại userId guest cũ 1. Xóa app hoàn toàn khỏi thiết bị
    2. Cài lại app
    3. Bấm button "ゲストとして利用する"    		 1. Secure storage đã bị clear khi xóa app
    2. App tạo guest mới (userId mới, email guest mới với suffix khác)
    3. Order history cũ không còn truy cập được (guest khác)    		 So sánh userId trước và sau khi cài lại High
    GM_LOGIN_TC_012 Guest Login BR-01 — Email format Medium Check email guest được sinh đúng format guest_<suffix>@eskitchen.local — 1. Đăng nhập guest
    2. Kiểm tra email được gán cho account (qua API response hoặc profile screen nếu có)    		 1. Email có dạng guest_<8 ký tự alphanumeric lowercase>@eskitchen.local
    2. Ví dụ hợp lệ: guest_a8f3k2x9@eskitchen.local
    3. Suffix chỉ gồm [a-z0-9], đúng 8 ký tự
    4. displayName có dạng ゲスト_<cùng suffix>    		 Regex kiểm tra: ^guest_[a-z0-9]{8}@eskitchen\.local$ Medium
    GM_LOGIN_TC_013 Guest Login BR-01 — Suffix uniqueness Medium Check suffix không bị collision khi tạo nhiều guest liên tiếp — 1. Gọi POST /auth/guest liên tiếp 10 lần (hoặc kiểm tra qua DB)
    2. So sánh email của các guest được tạo    		 1. 10 email guest đều khác nhau (suffix unique)
    2. Không có hai guest có cùng suffix trong cùng batch test    		 Gọi API 10 lần liên tiếp Medium
    GM_LOGIN_TC_014 Guest Login BR-02 — Account type High Check account type của guest = guest trong response và DB Đã gọi POST /auth/guest thành công 1. Kiểm tra response body của POST /auth/guest
    2. Kiểm tra field type (hoặc userType) trong response    		 1. Field type = guest trong API response
    2. Giá trị này phải phân biệt với registered    		 Inspect API response High
    GM_LOGIN_TC_015 Guest Login BR-02 — Double tap Medium Check không tạo duplicate guest khi bấm button Guest Mode 2 lần nhanh App ở màn Login, network bình thường 1. Bấm button "ゲストとして利用する" 2 lần liên tiếp rất nhanh (double tap) 1. Chỉ 1 request POST /auth/guest được gửi đi
    2. Chỉ 1 guest account được tạo
    3. Không có race condition tạo 2 account    		 — Medium

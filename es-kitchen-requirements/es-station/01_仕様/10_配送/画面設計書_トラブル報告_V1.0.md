## 2. 画面遷移 / Luồng điều hướng

```
【メインフロー / Flow chính】
ホーム(Home)
  └─[トラブル報告タップ]──▶ M01
                              ├─[ESへ電話する] → 電話アプリ起動（アプリ外）
                              ├─[トラブル報告へ] ──▶ S02
                              │                         └─[次へ] ──▶ S03
                              │                                        └─[送信] ──▶ M04
                              │                                                      ├─[送信する] ──▶ ホーム（送信成功）
                              │                                                      └─[キャンセル] ──▶ S03
                              └─[戻る] → ホーム

【修繕履歴経由フロー / Flow từ Lịch sử sửa chữa】
修繕履歴(S-REP)
  └─[トラブル報告タップ]──▶ M01
                              └─[トラブル報告へ] ──▶ S03（業者自動選択）
                                                       └─ 以降は同上
```

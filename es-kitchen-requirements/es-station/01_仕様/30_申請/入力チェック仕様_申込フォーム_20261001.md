# 入力チェック仕様（法人Web 申込フォーム・変更申請）2026/10/01

> 依頼者：Long（Tran Duc Long）／作成：Claude（Cowork）。STEP1 の決定 2-6「入力チェックは主要3項目（メール・郵便番号・電話）をデモに入れ、その他は仕様書に記載」に対応する資料。
> 対象：法人Web の申込フォーム（新規のお申し込み・お試し、変更のお申し込み8種類）と、運営の代理入力。
> 桁数は `法人拠点契約子契約_項目一覧.md` の型（varchar の長さ）に合わせた。項目一覧に型がないものは**案**と書いた。

## 1. 共通の決まり

| # | 決まり | 内容 |
|---|---|---|
| C1 | チェックのタイミング | 「確認へ進む」を押したときに、画面のすべての項目をまとめてチェックする。エラーの項目は赤枠にし、項目の下に文言を出す。最初のエラーの項目まで画面を動かす |
| C2 | 空欄 | 必須の項目が空欄のときは「必須チェック」だけを出す（形式のチェックは、値が入っているときだけ行う） |
| C3 | 前後の空白 | 前後の空白（全角・半角）は取り除いてから保存・チェックする |
| C4 | 全角・半角 | 数字・ハイフン・英字は、全角で入力されても半角に直してからチェックする（郵便番号・電話番号・FAX・メールアドレス） |
| C5 | 文字数 | 最大文字数を超えるときはエラー（自動で切り詰めない） |
| C6 | 機種依存文字 | 絵文字・制御文字は受け付けない。請求書・送り状に印字する項目（名称・住所）は JIS 第1・第2水準の範囲（**案**） |
| C7 | 二重送信 | 「送信」を押したらボタンを無効にし、受付番号が出るまで押せないようにする |

### エラーの文言（共通）

| 種類 | 文言 |
|---|---|
| 必須 | 【項目名】をご入力ください。（選ぶ項目は「【項目名】を選択してください。」） |
| 最大文字数 | 【項目名】は【n】文字以内でご入力ください。 |
| カタカナ | 【項目名】は全角カタカナでご入力ください。 |

## 2. デモに入れた形式のチェック（主要3項目）

| 項目 | 規則 | 文言 | デモ |
|---|---|---|---|
| 郵便番号 | 数字7桁。ハイフンはあってもなくてもよい（`^[0-9]{3}-?[0-9]{4}$`）。保存はハイフンあり（例：105-0011） | 郵便番号は数字7桁でご入力ください（ハイフンはあってもなくても構いません）。 | 入れた |
| 電話番号 | 数字とハイフンだけ。先頭は数字（`^[0-9][0-9-]*$`） | 電話番号は数字とハイフンだけでご入力ください。 | 入れた |
| メールアドレス | `@` の前後に文字があり、`@` のあとに `.` がある（`^[^@\s]+@[^@\s]+\.[^@\s]+$`） | メールアドレスの形式が正しくありません。 | 入れた |

**仕様として足すこと（デモには入れない）**

- 電話番号：数字だけで10桁または11桁（ハイフンを除いて数える）。最大20文字（varchar(20)）。
- メールアドレス：最大160文字（varchar(160)）。ドメインの部分に全角を含めない。
- 郵便番号の「住所検索」：該当なしのときは「該当する住所が見つかりません。手で入力してください。」を出し、入力はそのまま続けられる。

## 4. 変更のお申し込み（8種類）

すべての申請に共通：**開始したいサイクル月**（必須・今日の時点で選べるいちばん早いサイクル月以降）、**ご事情・ご要望**（任意・1,000文字・**案**）。

| 申請 | 必須の項目と規則 |
|---|---|
| プランの変更 | 変更後のプラン（いまと同じプランは選べない） |
| 配送の変更 | 配送方法（自動販売機の拠点は固定・選べない）、配送回数（標準以上）。「変更しない」ばかりのときは送れない（「変更する項目を1つ以上選んでください。」） |
| 設備の変更 | ご希望の内容、対象の設備（いまお使いのもの）、台数（1以上・いまの台数まで） |
| 拠点情報の変更 | 変更したいもの（1つ以上）。選んだものだけ必須：納品先名・カナ、住所一式（§3-1）、電話番号、請求書、ゲストモード（運営の承認が必要・D5）、納品不可曜日、設備の希望日（今日より後の日付）。**FAX はこの申請に入れない**（拠点管理の「編集」で即反映・U14） |
| 法人情報の変更 | 郵便番号・住所・電話・FAX（法人アカウントだけ申し込める） |
| 休止 | 休止の理由、休止中の設備、休止したい期間。**通算の休止が12ヶ月を超える期間は選べない**。再開予定月は必須（「未定」は選べない） |
| 再開 | 再開するサイクル月、再開後のプラン |
| 解約 | 解約日（ルールで選べるいちばん早い解約日以降のサイクル末日から選ぶ）、解約の理由 |

**承認待ちの申請がある拠点**は、新しい申請を送れない（「承認待ちのお申し込みがあるため、承認後にお申し込みください。」）。

## 5. 運営の代理入力

- §3・§4 と同じ規則でチェックする。
- 運営だけの項目（お試し期間月数、ES-QR の利用設定、アカウントを発行するか など）は、運営の画面の規則に従う。
- 代理入力の受付方法（電話・メールなど）は必須。

## 6. 要確認

1. 設置フロア・備考・ご要望の最大文字数（案のまま決めてよいか）
2. 添付ファイルの種類（Word・Excel を受けるか）
3. 名称・住所に使える文字の範囲（C6）

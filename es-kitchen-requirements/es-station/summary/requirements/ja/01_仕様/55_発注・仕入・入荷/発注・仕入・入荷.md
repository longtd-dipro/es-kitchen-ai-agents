## 1. 全体の流れと時期

```
メニューを作る → 仮発注（メニューの公開の前）→ 公開・オーダー受付（前月1日〜15日）
 → 本発注 前半（A・B 週の便の分）→ 仕入先が承認 → 出荷報告 → 入荷の記録 → 倉庫在庫 → ピッキング・出荷
 → 本発注 後半（C・D 週の便の分）→ （同じ）
```

| 節目 | いつ | 根拠 |
|---|---|---|
| 仮発注 | **メニューを公開する前**（公開の条件に「仮発注 承認」がある）。仕入先に一定量の準備をお願いするもの | 台帳 I |
| 本発注 前半 | A・B 週の便の分。**前のサイクルの B5〜C1** | 台帳 I |
| 本発注 後半 | C・D 週の便の分。**D5〜次のサイクルの A1** | 台帳 I |
| 本発注のリマインド | 時期の始まりと最終日に、運営の**システム管理**の役割へ通知 | 台帳 E |
| 追加発注 | オーダー締切の後に増えた分（お試しの自動オーダー・締切後に承認した申込・営業サンプルの締め後の追加・代替品）。**新しい発注データ（本発注）**として作り、理由を残す。基準日は B7・D7 | 台帳 I・H・J |
| 資材 | 仮発注なし。**本発注だけ・随時**（§9） | 台帳 I |

- 発注の締めは**オーダー締切で自動**。手で締める・解除する操作はない（REQ-PO-108・109）。
- 本発注の時期を過ぎた便の日付の移動は制限がある（1便ずつ・理由必須・同じ半分〈A↔B／C↔D〉の中。別のサイクル・別の半分へはトラブルの対応のときだけ）。配送の仕様を見る。

## 3. 発注の状態

`仮発注 → 納期回答待ち → 納期回答済み → 本発注 → 本発注の承認待ち → 本発注承認済み → 出荷済み → 入荷済み`
ほかに **受注不可**（仕入先の回答）と **キャンセル**（運営）。（REQ-PO-111）

| いまの状態 | だれが・何をすると | 次の状態 |
|---|---|---|
| 仮発注（納期回答待ち） | 仕入先が納期を回答 | 納期回答済み |
| 納期回答済み | 運営が本発注（時期は §1） | 本発注の承認待ち |
| 本発注の承認待ち | 仕入先が**納品日・入荷箱数・賞味期限（必須）**を入れて承認（運営の代理入力も可） | 本発注承認済み |
| 納期回答待ち・本発注の承認待ち | 仕入先が受注不可（理由を選ぶ・コメント必須） | 受注不可 → 運営が別の仕入先へ手配するかキャンセル |
| 本発注承認済み | 仕入先が出荷報告 | 出荷済み |
| 出荷済み | 入荷を記録（§8） | 入荷済み（差異があれば対応待ち） |
| どれでも | 運営がキャンセル | キャンセル（消さない・仕入先の画面にも残す） |

## 9. 資材の発注

- 仮発注なし・**本発注だけ・随時**。納入先は **ES事務所（資材）**（倉庫マスタ・THOMAS 連携なし）。入荷は運営が入れる（台帳 I）。
- 資材の在庫は、**ES事務所とすべてのピッキング倉庫**で持つ。資材は食品の便と一緒には送らない（資材便）（課題一覧 2-5・2026/10/02）。
- お客様の資材の注文は `50_注文/注文.md` §9。

## 11. 期限（賞味期限・消費期限）

- 仕入先に伝える希望の期限＝顧客納品日＋保証日数（§5-10）。
- 本発注の承認で仕入先が賞味期限を入れる（**必須**・台帳 E）。出荷報告でも入れられる。入荷の記録でも**必須**（§8-2b）。
- 商品マスタの ES賞味期限・短消費期限は、発注の画面で**期限の日を計算**するのに使い、期限が切れた在庫の**廃棄の提案**につなげる（課題一覧 2026/10/03）。

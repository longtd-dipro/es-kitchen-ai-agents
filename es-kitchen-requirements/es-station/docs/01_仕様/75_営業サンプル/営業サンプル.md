## 1. 種類

| 種類 | 何か | フェーズ2 |
|---|---|---|
| **営業サンプル** | 見込みのお客様へ送る試供品 | **システムで管理する**（下の §2） |
| **試験用サンプル**（保管・試験予備・試食用） | ESキッチンの中で使う | **今のやり方のまま**：ESキッチン用の拠点・契約から普通に注文する（契約経由）。「ES 製造商品」のフラグ・自動作成は作らない |
| 工場のスペシャルサンプル・生産との連携 | — | 将来 |
| キャンペーンの実施履歴・成功率の編集 | — | 作らない（2026/07/08） |

- 顧客ステータス「サンプル」「無料試し」は作らない（お試しは契約で表す。サンプルは宛先に履歴を持たせる）。

## 2. 営業サンプル

| # | 決まり | 根拠 |
|---|---|---|
| 2-1 | 受付は**システムの中**で入れる。運営Web の**サンプル専用の簡易登録**。入れるのは**宛先だけ**（法人・拠点・契約は作らない） | STEP1（2026/10/01） |
| 2-2 | **件数はメニューごと**に決める（メニュー作成の画面。既定は月60件＝15件×4・足せる・メニューの公開〈締切〉まで直せる）。毎週15件の固定はやめた | MM 2026/10/02、RD-MN-045 |
| 2-3 | 営業サンプルに使う商品は、商品マスタ／メニュー作成の画面の「営業サンプル」のチェックで決める | 2026/06/26 |
| 2-4 | **枠の件数は宛先1か所＝1件**（2回登録は2件）。商品ごとの数量は1〜9個（初期値は各2個。選んだ商品をまとめて一括変更できる） | T4-4、台帳 F 2026-10-08 |
| 2-5 | **発送日**：納品日を入れ、リードタイムから逆算する。ピッキングできない日に当たれば直前のピッキングできる日に前倒しし、**納品日も同じだけ動かす**（契約の配送と同じ） | 要件 行182、T4-5 |
| 2-6 | **ピッキング倉庫は宛先ごと**（商品ごとではない）。登録のたびに配送ルート（ピッキング倉庫・配送会社・中継先）を都度入れ、その倉庫が扱わない商品は選べない（倉庫に担当エリアは持たない）。**倉庫が分かれる出荷（枝番）は作らない：別の倉庫の商品は、もう1回登録する**（枠は2件・同じ宛先への2回目は警告）。倉庫を変えたとき、新しい倉庫が扱わない商品の選択は外れ、**数量は残す** | 台帳 F 2026-10-08（営業サンプルの配送ルート）、台帳 S（#448） |
| 2-7 | リードタイムは宛先（受け取る会社の住所）ごとに違い、毎回違うことがある。**登録のたびに運営が手で入れる**（必須・整数0〜30日。システムは提案しない）。発送日＝納品日−リードタイム。倉庫ごとのリードタイムは持たない | 台帳 F 2026-10-08（営業サンプルのリードタイム） |
| 2-8 | **一覧と CSV 出力**。宛先ごとの履歴 | 2026/08/19、STEP1 |
| 2-8b | **法人とはつながない**（その会社があとで申し込んでも引き継がない）。あとで分かったことはメモの欄に書く | 台帳 N（hong 2026-10-05） |
| 2-9 | **受付の締めのあとも足せる。** ただし締めのあとに足した分は**出荷指示を作らない**（状態「締め後追加」）。締め後追加のサンプルも取り消せる（2-12） | 2026/08/19、台帳 S（#449） |
| 2-10 | 締めのあとの余りは、在庫戻しの出荷指示（`60_在庫/在庫.md` §2-6）で ES へ戻す | 要件 行99 |
| 2-11 | 発注の必要数に入る（必要数＝契約の注文＋お試し＋営業サンプル）。締めのあとに増えた分は追加発注。営業サンプルの数の数え方は 2-16 | `55_発注・仕入・入荷/発注・仕入・入荷.md` §1・§2 |
| 2-12 | **取消**：受付済はいつでも（すぐ）取り消せる。**締め済と締め後追加は、そのサンプルの発送日の前日 23:59（日本時間）まで**取り消せる。発送日以降は取り消せない（在庫戻しなどで対応）。理由は必須。状態「取消」は枠に数えず、一覧は既定で出さない。締め済の取消は、THOMAS へ変更行の CSV を出して再登録する（台帳 L の出荷指示後の変更と同じ方法） | 台帳 F 2026-10-07、台帳 S（#449） |
| 2-13 | **受付の締め**：自動（出荷週の月曜の2営業日前【仮・運営の設定で変えられる】）と、運営が「受付を締める」で早く締める手動の両方。締めると受付済に出荷指示を作り、THOMAS 用 CSV と配送データ（2-17）も同時に作る | 台帳 F 2026-10-07・10-08 |
| 2-14 | **締めの取消**：その出荷週の**最初の発送日の前日 23:59（日本時間）まで**できる（取り消すと、その週の出荷指示と配送データを取り消し、変更行の CSV を出して再登録する）。**手動で締めを取り消した週は、自動締めが再び動かない**（運営が手で締め直す）。取消（2-12）の期限は各サンプルの発送日、締めの取消の期限は週の最初の発送日 | 台帳 F 2026-10-08、台帳 S（#449） |
| 2-15 | **月の枠**：受付済の宛先の数で数える（取消は数えない）。**枠を超える登録は止める**（E149）。枠が未設定の月は警告して登録できる | 台帳 M-5・F、hong 確認 2026-10-08（台帳 S #448。台帳に行はない） |
| 2-16 | **見込み在庫と発注**：サンプルの出荷指示は、受付を締めて出荷指示ができてから見込み在庫（倉庫在庫の出荷予定）から引く（締める前の受付済は引かない）。**発注に出す数**は、対象商品ごとに「実際に登録された数量（受付済）＋枠の残り件数×2個」。締めのあとに増えた分の扱いは次回に決める | 台帳 S（#448）、台帳 F 2026-10-08 |
| 2-17 | **配送データ**：受付を締めたとき、出荷指示と同時に作る。運営D の出荷・配送管理の一覧には**種類「サンプル」**で出し、**契約・拠点は空**、**1日300件の上限の件数に数える**。委託配送先Web での見え方は OW の設計書で決める | 台帳 F 2026-10-08、台帳 S（#451） |

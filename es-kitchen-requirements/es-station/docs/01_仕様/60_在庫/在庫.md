## 1. 言葉

| 言葉 | 意味 |
|---|---|
| 倉庫在庫 | ピッキング倉庫（関東・関西〈THOMAS〉・ES事務所）にある数 |
| 拠点在庫 | お客様の拠点の冷蔵庫・自販機にある数。**拠点ごと**に持つ |
| 理論在庫 | システムが計算した拠点在庫（納品 − 購入 − 廃棄 ± 調整）。**マイナスになってよい** |
| 実在庫 | 棚卸しで数えた数 |
| 仮確保 | 注文（支払い前）で押さえている数 |
| 利用可能在庫 | 理論在庫 − 仮確保 |
| 棚卸報告 | 拠点の在庫点検の申告（画面の名前。旧「在庫点検の申告」） |
| 管理ロス | 理論在庫 − 実在庫（お金に直して、免責金額を超えた分を請求） |

## 3. 拠点在庫の増減

| 増える | 減る |
|---|---|
| 納品（便ごとに**足していく**。リセットしない） | 個人アプリ・ESQR の購入（支払い完了） |
| 在庫の移動で入る（運営） | 廃棄の登録 |
| 運営の在庫調整（＋） | 在庫の移動で出る・運営の在庫調整（−） |

- 棚卸しの締めのあと、**理論在庫を実在庫で上書き**し、次の期の始まりにする（REQ-PO-418b）。
- 棚卸しの日より後に届いた便は、**次の棚卸しに入れる**（課題一覧 4a-11・2026/10/03）。
- 賞味期限・ロットは便ごとに持つ。
- **新システムへ切り替えるとき**：購入はロックしない。理論在庫は 0 から始め、前から残っている商品はスキャンで買える。法人Web に「最初の棚卸報告をしてください」と、報告するまで出す。**切り替えたあとの最初の棚卸報告までは管理ロスを出さない**（台帳 N・hong 2026-10-05）。**理論在庫がない商品は買い物の一覧に出さない**（スキャンだけ）（~~旧~~ 2026-10-08 に置き換え：初回棚卸しまでも今のフェーズ1と同じ表示〈2ヶ月分のメニュー〉。台帳 O「初回棚卸し前のメニュー表示」）。棚卸報告で理論在庫が計算できたら在庫がある商品が出る。既存のお客様は2月の配送データを取り込んで理論在庫を計算し、2月15日〜3月20日に棚卸報告（必須）、月末に運営が在庫調整、4月の実績精算へ（台帳 N・hong 2026-10-06）。

### ①の帰結（お試しが複数拠点可）

- お試しの**親契約は拠点ごとに1つ**（本導入と同じ）。拠点3つなら親契約3つ。
- 契約一覧で拠点を増やす形は、本導入とまったく同じ操作になります。
- ただし **お試しは「初回利用企業限定」** なので、**法人単位で1回だけ**という制限は残るはずです（§8 ⑭）。
- **キャンペーン割引を拠点ごとに効かせるのか、法人で1回だけか**も決める必要があります（§8 ⑮）。

### ⑦の帰結（担当者は法人・拠点それぞれ）

```
法人のご情報
  └ 担当者テーブル … メイン1名・請求1名が必須

拠点（希望プラン）ごと
  └ □ 法人の担当者情報と同じ        ← 旧フォームにあったチェックを復活
  └ 担当者テーブル … メイン1名が必須
                     請求先＝この拠点 のときは請求1名も必須
```

- 現行フォームの「納品先別の担当」（1つの表で拠点を紐づける）は**廃止**します。
- 代わりに旧フォームの **「法人の住所情報が同じ」「法人の担当者情報が同じ」のチェック**を活かします。1拠点だけのお客様は、実質1回の入力で済みます。
- 現行フォームの「**納品先（拠点）情報からコピー**」（拠点 → 法人）は残します。向きが逆なので両方あってよいものです。

## 6. 自動販売機の導線 — ご提案

### 6-1. まず前提の確認（機種マスタと合わせて）

機種マスタの機種区分は**5つ**です。

| 機種区分 | 接頭辞 | 申込フォームでの立ち位置（提案） |
|---|---|---|
| 冷蔵庫・冷凍庫 | `RF` | **メインの設備**（どちらか一方を選ぶ） |
| 自販機 | `VM` | **メインの設備**（どちらか一方を選ぶ） |
| 電子レンジ | `MW` | 付ける追加設備（オプション） |
| ホットウォーマー | `HW` | 付ける追加設備（オプション）※旧フォームに出てこない（§8 ⑯） |
| 資材ボックス | `BX` | プランに連動して自動で付く／追加できる |

> **先に1件お詫びと訂正です。**
> いま作っているデモで、電子レンジに `VM000001` を使っていました。
> 正しくは **`VM`＝自販機・`MW`＝電子レンジ**です。運営デモ・法人サイトデモとも直します（§7 #15）。

### 6-2. 提案：**拠点ごとの「設備タイプ」の2択に戻す**（旧フォームと同じ形）

希望プラン（＝拠点＋契約）のアコーディオンの**いちばん上**に、2択のトグルを置きます。

```
希望プラン 1　東京本社
 ┌──────────────────────┬──────────────────────┐
 │  冷蔵庫・冷凍庫（標準）   │      自動販売機        │   ← ここで切り替える
 └──────────────────────┴──────────────────────┘
   ES食品数（プラン）＊ / コース＊ / 配送方法＊ / 配送回数 / 契約開始希望年月＊
   （自販機のときだけ）設置フロア
   プラン外の備考
   オプション（設備タイプで中身が変わる）
   納品先情報
```

**この案を推す理由**

1. **現行フォームの確認画面に、すでに「設備タイプ」の行があります。**拠点ごとに持つ前提の設計になっているので、入力側をそこに合わせるのが素直です。
2. **拠点ごとに違う設備を選べます。**「本社は自販機・支店は冷蔵庫」が1回のお申し込みでできます。
3. **契約区分（お試し／本導入）と直交します。**区分のトグルを3つに増やすと、種類の違うものが1列に並んで分かりにくくなります。
4. **旧フォームと同じ形**なので、社内で説明しやすいはずです。

**呼び方の提案**

| | 提案 | 理由 |
|---|---|---|
| 項目名 | **設備タイプ** | 現行の確認画面がこの名前を使っているため |
| 選択肢 | **冷蔵庫・冷凍庫** ／ **自動販売機** | **機種マスタの機種区分の呼び方に揃える**ため |
| 廃止 | ~~設置型~~ ／ ~~標準設備（冷蔵庫・冷凍庫）~~ | 確認画面の「設置型」は何を指すか分からず、「標準設備」は長いため |

### 6-4. 提案：**お試しキャンペーンは冷蔵庫・冷凍庫のみ**

旧フォームでも、お試しを選ぶと設備タイプの2択が出ませんでした。理由もはっきりしています。

- お試しは**無料・1か月**
- 自販機は**在庫状況によって対応まで数か月**かかる

1か月のお試しに、数か月かかる設備は合いません。
**お試しを選ぶと設備タイプのトグルを隠し、冷蔵庫・冷凍庫で固定する**のがよいと思います。
自販機をご検討中のお客様には、その場で「**自販機は面談でご相談ください**」の案内を出します。

### 6-5. 提案：**別途見積のときの合計の出し方**

拠点ごとに設備タイプが違うと、合計が出せる拠点と出せない拠点が混ざります。
**金額の出る拠点だけ合計し、自販機の拠点数を併記する**のがよいと思います。

**右サイド（拠点ごとの見積）**

```
冷蔵庫・冷凍庫の拠点            自動販売機の拠点
┌────────────────┐        ┌────────────────┐
│ プラン小計   49,500円 │        │ プラン小計      ― 円 │
│ オプション小計 5,000円 │        │ オプション小計   ― 円 │
│ ─────────────── │        │ ─────────────── │
│ 見積合計              │        │ 見積合計             │
│   54,500 円/月        │        │   別途見積            │
└────────────────┘        │ ※後日担当者よりご連絡  │
                                └────────────────┘
```

**確認画面のお見積料金内訳**

```
お見積料金内訳（税別）                          月額基本料金合計（税別）
基本プラン合計（2拠点）  ¥39,000                      ¥51,800 / 月
追加レンジレンタル       ¥5,000                  ＋ 自動販売機 1拠点は別途見積
初期配送設置パック       ¥7,800
※ 自動販売機の拠点（名古屋支店）は別途お見積りのうえ、担当者よりご連絡します。
```

- 合計の見出しに「**（2拠点）**」と入れて、**全拠点ぶんでないことが分かる**ようにします。
- 確認画面のマトリクスでは、自販機の列の「プラン料金合計」を **`別途見積`** と出します。

### 6-6. 検討したが採らなかった案

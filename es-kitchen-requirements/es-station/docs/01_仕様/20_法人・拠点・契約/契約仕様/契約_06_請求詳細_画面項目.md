### 0.8 子契約の請求額は ① 固定額（前払い）と ② 実績精算（後払い）の2表に分ける（2026/09/15）

1つの子契約の金額は、**確定するタイミングも、乗る請求書も違う2種類**が混ざります。1つの表にまとめると何月分の請求か分からなくなるため、**表を2つに分けます**。

| | ① 固定額（前払い）の請求額 | ② 実績精算（後払い）の請求額 |
|---|---|---|
| 中身 | プラン固定額・オプション・設備・値引き・スポット費用 | 棚卸の結果から出る精算差額（免責を超えた分）・現金回収差額・**価格調整差額（② の内訳の1行。③ ではない。台帳 F 2026-10-08）**。繰越・相殺は ③ 調整明細で持つ（旧：前月からの繰越調整。2026-10-03 契約_01 §3 に合わせて修正） |
| 対象期間 | 契約・サイクル月の1サイクル（A1〜D7）（旧：暦月の1ヶ月 例 2026/07/01〜07/31。2026-10-03 契約_00 §0.3 に合わせて修正） | 前月21日〜当月20日（例 2026/06/21〜07/20）。**20日締め**。リードタイムの影響を受けない |
| 請求月 | 契約・サイクル月 ＋ 請求書発行リードタイム（−3〜+1。例 サイクル月 2026-07・−1 → 2026-06）（旧：サイクル月 − リードタイム。2026-10-03 請求ルール 1-2 に合わせて修正） | **サイクル月の翌月**（例 2026-08。8/1 発行）（旧：7/31 発行。2026-10-03 台帳に合わせて修正） |
| 確定タイミング | 請求月の前月25日（例 請求月 2026-06 → 2026/05/25 確定・6/1 発行）（旧：請求月の25日。2026-10-03 台帳に合わせて修正） | 締め（20日）の後の25日（例 2026/07/25） |
| 乗る請求書 | 例 INV-2026-06-001 | 例 INV-2026-07-001 |
| 請求ステータス | 生成済／① 固定額 確定／拠点確定／法人確定／請求済 | 未集計／② 実績精算 確定／拠点確定／法人確定／請求済 |

- **子契約に請求書番号は1つではありません。** ① と ② はそれぞれ別の請求書に乗るため、請求書番号・請求ステータス・確定者／確定日時は **①② それぞれの表が持ち主**です。契約タブには「請求の状況（参照）」として両方をまとめて表示するだけにします。
- **行ごとに「対象期間」の列を持ちます。** 既定は表の対象期間ですが、スポット費用は別の月を指定できます。繰越・相殺は ③ 調整明細が元の請求書・元のサイクル月を持ちます（旧：繰越調整は元の期間を入れる。2026-10-03 契約_01 §3 に合わせて修正）。**スポット費用の対象月を費目名のカッコ書きで書く運用は廃止**します（REQ-CT-236）。
- 金額サマリーの**合計（①＋②）は参考値**です。**この子契約の** ① と ② は確定タイミングも乗る請求書も違うため、1枚の請求額ではありません。
- ただし**1枚の請求書には ① と ② が両方入るのが普通**です。ある月に出す請求書は「**これから納品する月の前払い分**」と「**締まったばかりの月の実績精算分**」を一緒に載せます（別々の子契約から来ます）。例：2026/08/01 に発行する請求書（請求書発行リードタイム＝1ヶ月前（−1））＝ 2026-09 サイクル分の前払い ＋ 2026/06/21〜07/20 の実績精算（7/25 に確定した 2026-07 サイクル分）（旧：2026/08/01 に送付する請求書（リードタイム1）。2026-10-03 台帳に合わせて修正）。請求書全体は法人・拠点の**請求書一覧**で見ます。
- 表の区分そのものが ①／② を表すので、行に「請求区分」の列は持ちません。
- **金額は税抜で持ちます（2026/09/25 決定）。** 費目行は税抜金額＋税率。消費税は請求書で税率ごとに計算して上乗せし、請求書一覧に「消費税」の列を出します。端数は請求書ごと・税率ごとの合計に四捨五入（負の額は絶対値で四捨五入）。拠点ごとの税は参考、法人の税額が正（旧：切り捨て・デモの仮置き。2026-10-03 請求ルール 2-4 に合わせて修正）。オプションマスタ・値引きマスタ・機種マスタも税抜で持ちます。
- 締め・確定・発行の日（請求ルール 1-1）、入金期限（1-5）、請求ステータスの表示の段階（1-6）、消費税（2-4）は 請求ルール が正。

### タブ：③ 調整明細（2026-10-03 追加）

**③ 調整明細**　<small>請求（子契約）</small>

項目：元の請求書／元のサイクル月／**種類（相殺・差額・繰越・再請求。運営が手で入れた行は「手入力」）**／理由／税抜金額／税率／載せた請求書。**①②は参照専用で、手入力の調整はこの ③ に集約**する。毎月かかる調整は「**毎月（継続）**」と書く（「繰越」は未入金の再請求の意味でだけ使う）。価格調整差額は ③ ではなく ② の内訳の1行。（台帳 F 2026-10-07 Q-E4・2026-10-08 に合わせて追記）承認時に請求済みの月ごとの差額をシステムが自動で作り、次の請求書を作るときにまだ載っていない調整明細を拾う（契約_01 §1-1・§3）。

# Mail List に足すメール：パスワード設定のご案内（2026-10-07・hong 回答）

**目的**：運営Web の仕入先・委託配送先の詳細にある「パスワード送信」ボタン（確認 Q173 → 成功 S173）で、メイン担当者のメールアドレスにパスワード設定のご案内を送る。

**配送スタッフ**は、ドライバーアプリの「パスワードリセット」と同じ4桁の認証コード（Mail List **No.3**）を送る（新しい行は不要）。

**Mail List（Excel・正）へは hong がローカルで貼る。** CSV の写し（`MessageList_MAIL_20261001.csv`）には **No.30** として追加済（2026-10-07）。貼ったら `ml_export.py` で CSV を更新する。

| 項目 | 内容 |
|---|---|
| No. | **30** |
| 利用ケース | 【フェーズ2】仕入先・委託配送先のパスワード設定のご案内（運営の詳細画面「パスワード送信」） |
| 送信元 | 【ESステーション】ESキッチン運営 no-reply@es-kitchen.co.jp |
| 送信対象 | 仕入先・委託配送先のメイン担当者のメールアドレス |

| 件名 | 【ESステーション】パスワード設定のご案内 |

```

※ 本メールにお心当たりがない場合は、本メールを破棄してください。
※ 本メールは送信専用のため、返信できません。

──────────────────────────
ESキッチンサポート窓口
ESキッチン株式会社
```

## 要確認
- **有効期限（24時間）は仮**。実際の期限は開発の設定に合わせる。
- パスワード設定のURLは、運営が押すたびに新しいものを作る（古いURLは使えなくする）案。

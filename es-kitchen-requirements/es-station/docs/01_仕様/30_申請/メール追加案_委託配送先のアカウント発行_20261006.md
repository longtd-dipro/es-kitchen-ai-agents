# Mail List に足すメール：委託配送先のアカウント発行（2026-10-06・hong 回答）

**目的**：運営Web の委託配送先マスタの「アカウント一括発行」（台帳 138：フェーズ2でやる）で、委託配送先のメイン担当者にログイン案内を送る。いまの Mail List には仕入先向け（No.26）はあるが、**委託配送先向けの行がない**。

**Mail List（Excel・正）へは hong がローカルで足す。** この文書は文面の案。足したら `ml_export.py` で CSV の写しを更新する。

## 関連
- 状態が「無効」「削除済」の委託配送先はログインできない（台帳 F「運営Web マスタ…の登録・編集・削除」）。

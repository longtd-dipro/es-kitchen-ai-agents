## 1. Mục tiêu và phạm vi

**Mục tiêu:** xác nhận dữ liệu và trạng thái đi xuyên được từ site này sang site khác đúng spec, theo chuỗi ID:
`AP-`(申込) → `CU`(法人/拠点) → `CP…-YYYYMM`(子契約) → `O-YYYYMM-拠点ID`(注文) → `PO-`(発注) → 入荷 → `DL-`(配送) → 棚卸報告 → 実績精算 → `INV-`(請求書).

**Trong phạm vi (luồng chính E2E, F1〜F5):** 6 site (法人Web / 運営Web / 仕入先 / 委託配送先 / ドライバー / システム管理) + cắt ngang: 権限・CSV・メッセージ・ngày biên (15/20/25/1).
**Luồng phụ (F6, chạy sau khi F1〜F5 ổn):** 変更申請 (プラン変更・休止・再開・解約), 代替品・トラブル, 追加発注, お試し→本導入.
**Ngoài phạm vi:** 個人アプリ/ESQR (chỉ kiểm điểm giao: giá trị thanh toán → 理論在庫), mail thật, Bill One/THOMAS/ヤマト/Cognito/HubSpot thật (台帳 E: demo chỉ là hình mẫu, lỗi chỉ tái hiện ở giai đoạn test theo `外部連携_エラーの流れ_一覧`), hiệu năng, responsive (đang làm riêng, HANDOFF §2).

## 3. Cách chấm (BA / QA / QC)

| Vai trò | Làm gì | Đầu ra |
|---|---|---|
| **BA** | Với mỗi bước: spec/台帳 nói gì, màn hình spec (`05_画面設計書/データ/*.py`) nói gì, code làm gì → có 3 chỗ khớp không. Đánh dấu nơi hai tài liệu mâu thuẫn (xem §6) | cột "Căn cứ" + danh sách mâu thuẫn |
| **QA** | Chạy luồng thật trên app theo đúng bước, đối chiếu "Kết quả mong đợi" (trạng thái, ID, số tiền, thông báo), chụp ảnh | cột Pass/Fail/Blocked + ảnh |
| **QC** | Ca biên/ca lỗi/quyền/trùng lặp/ngày giới hạn (đánh dấu 🅒), tìm chỗ nhập sai vẫn qua được, chỗ không có spec | cột 🅒 + lỗi mới |

Mức độ: **P1** = chặn luồng chính; **P2** = sai tiền/trạng thái/quyền nhưng đi tiếp được; **P3** = văn bản/hiển thị.
Kết quả: ✅ Pass · ❌ Fail · ⛔ Blocked (chờ hong chốt §6 hoặc thiếu spec) · ➖ Chưa chạy.

## 4. Thứ tự chạy và phụ thuộc

```
F0 Smoke ─► F1 申込→契約 ─► F2 メニュー→注文 ─► F3 発注→入荷 ─► F4 出荷→配送→納品 ─► F5 棚卸→精算→請求
                                   │                    │                         │
                                   └──── F6 luồng phụ (変更/休止/解約/代替品/追加発注) ────┘
Cắt ngang (X): 権限 · CSV · ngày biên · メッセージ — chạy xen kẽ ở mỗi luồng
```

Mỗi luồng reset DB → chạy → chạy `check/run`. Luồng sau **dùng dữ liệu do luồng trước tạo** trong cùng một lượt (để thử xuyên suốt), nhưng cũng có bản "chạy riêng từ seed" cho những ca độc lập.

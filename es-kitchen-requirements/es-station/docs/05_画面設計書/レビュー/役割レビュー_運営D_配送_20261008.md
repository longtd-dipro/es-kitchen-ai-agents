## QC テスト観点の種

### AW_SCHD（スケジュール 001〜006）
- 経理で開く → 一括承認・出荷データの移動・配送サイクル設定のボタンが出ない（CSV 出力は出る）
- 物流で開く → 配送サイクル設定ボタンが出る／営業・CS で開く → 出ない
- 予定の月（2026-11）を開く → 予定の月のサイクルの日すべてに点線の枠が付く（付かない日がない）
- 週で「全て選択」→ 画面外の「ほか n件」も含め件数が選択バーに出る／出荷日が今日以前の配送は選べない
- 移動の小窓：出荷日の前日までに移動／出荷日当日・過去へ移動 → 前者は実行、後者は日が非活性（直接入力は E163・E161）
- 移動の理由を500字ぴったり／501字／空白だけ（本発注の後の便）→ 500字は通る、501字は E04、空白だけは E01
- 移動で13便→16便目の配送が15件超え → W131 が出て止めない／出荷300件超え → W130 が出て止めない
- 変更申請の一括承認で、選択中の1件を別の人が先に承認 → E31 または成功分のみ承認（7 の決定どおり）、S11 の件数が実際と一致
- 資材タブで予定の月（2026-11）→ 表なしで案内 I145／食品側の便種別に資材便がない

### AW_CYCL（配送サイクル設定 001）
- 経理（Ad00012）が /ops/delivery/schedule/cycle を直接開く → 画面なしで E32、メニューにも入口なし
- 物流で休日を追加して保存 → 保存できる（5 の決定どおり）／営業で保存 → 不可
- A1 に火曜（2026-12-08）→ 項目の下に E166、トーストは出ない／確定済みの月を選ぶ → A1 は入力不可で「（見るだけ）」の理由
- 設定対象期間：開始月 2027-05、終了月を開始月+6か月以上 → 開始月+5か月に丸め I140／終了月＜開始月 → E174
- 休止 2026-12-29〜12-31（3日）→「あと4日」・E168 で保存できない／区分＝調整4日を足す → 保存できる
- 休止の期間名60字ぴったり／61字／空白だけ → 60字は通る、61字は E04、空白だけは E01
- 祝日・臨休で同じ日付を2回追加 → E09／削除ボタン → 確認なしで消える（または Q01。10 の決定どおり）
- 「この設定を3倉庫へ反映」→ Q133 → 反映する／キャンセル → 前者は3倉庫が上書き、後者は変更なし
- 保存確認：予定のある日を休業に足して保存 → 影響の表（作り直し n／要確認 m／出荷指示済み k）・確認チェックなしで「確認して保存」不可
- 「確認して保存」を連打／別の人が先に保存 → 1回だけ保存／E31

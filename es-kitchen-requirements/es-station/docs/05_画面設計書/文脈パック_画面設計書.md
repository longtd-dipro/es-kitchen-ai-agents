## 0. Đọc gì, KHÔNG đọc gì
**Đọc ngay (theo thứ tự):** file này → `並列実行計画_画面設計書.md` mục 4B (dòng của cụm mình) → code của cụm (`app/<site>/…`, `lib/<site>/areas/…`; dùng `Grep`/đọc từng phần, không đọc cả thư mục) → grep `docs/決定台帳.md` và `docs/決定の受付簿.md` theo tên 機能 (không đọc hết).
**Không đọc cả file:** `データ/*.py` mẫu (100〜240 KB mỗi file!), `_共通_メッセージ.py` (70 KB), `HANDOFF_cloud.md` (47 KB), `docs/01_仕様/00_決定/` (đã đóng băng). Dùng `grep`/`sed -n` đúng đoạn cần.
**Không đọc PNG.** Không chạy `--review`, Excel (`--release`) trong cụm. cloud không thấy `00_確認してほしい/`, Excel, ảnh gốc.

## 1. Quy trình 1 phiên / 1 cụm (một lượt, ít tốn nhất)
1. Chốt danh sách trạng thái (VIEWS: id + cách tạo) cho từng 機能, **trước khi viết** (thêm sau làm lệch số).
2. Đọc code + 台帳/受付簿 liên quan → liệt kê chỗ chưa rõ / mâu thuẫn / (案) / 仮.
3. Viết data **chỉ tiếng Nhật** (`vi=""`, `ex` chỉ giá trị). Phần chưa rõ → `open`/`chk`, **không đoán**. Dùng `kd_scaffold.py` để ra khung, 機能 đầu cụm làm kỹ, các 機能 sau sao theo mẫu đó.
4. **Hỏi hong 1 lần, 1 bảng** (5〜10 dòng: `#｜trích nguyên văn｜nguồn｜lựa chọn｜đề xuất`). Dòng không có trả lời = theo đề xuất. Tách riêng chỉ khi: đảo quyết định cũ / tiền・quyền・pháp lý / ảnh hưởng lớn. Cái đã có chuẩn (`input_standard.md`, 台帳) thì áp dụng, không hỏi.
5. Phản ánh câu trả lời vào data (`DECISIONS`, bỏ `open`); **ghi 台帳 + 受付簿 trong cùng commit** (cái cũ chuyển sang「置き換えた旧決定」). Quyết định khác 台帳 → hỏi lại kiểu「○/○ に △ と決めています。□ に変えますか？」.
6. **1 lần Haiku/Sonnet** (Agent): điền `vi` và giải thích `ex` bằng tiếng Việt cho toàn cụm, "không sửa phần tiếng Nhật".
7. `make.py --check` về 0 → `npm run dev` (`NEXT_PUBLIC_DEMO=1`, nền) → `--capture` (chỉ trạng thái đổi) → `--only html` 1 lần → commit data + HTML → dừng server.
8. `HANDOFF_cloud.md`: thêm 3〜5 dòng log (không dán lại nội dung).

## 2. Lệnh (từ thư mục gốc repo)
```bash

python3 $S/kd_scaffold.py http://localhost:3000/<url> --login-id Ad00010 > /tmp/..   # khung (scratchpad)
python3 $S/make.py --check   $D/<Code>_<機能>.py        # không cần browser, lặp thoải mái
python3 $S/make.py --capture $D/<..>.py                 # --views 003,007 / --force
python3 $S/make.py --only html --book <ブック> $D/<..>.py
```
- Dev server: `NEXT_PUBLIC_DEMO=1 npm run dev` (`run_in_background`), chờ bằng `Monitor` + `until curl -sf http://localhost:3000/`. Dừng: `fuser -k 3000/tcp` (**không** dùng `pkill -f "next dev"`).
- `--capture` chỉ lấy lại trạng thái đã đổi; `CODE_PATHS = ["app/<site>/<機能>", "lib/domain/seed"]` để sửa 機能 khác không làm chụp lại.
- Đăng nhập mẫu (`lib/domain/seed/account.ts`): 運営 `Ad00010` (site `ops`). Site khác: xem file đó, `LOGIN = {"site": "<corp|carrier|driver|supplier>", "loginId": "…"}`.
- `POST /api/dev/reset` đưa DB về dữ liệu mẫu; muốn trạng thái mà dữ liệu mẫu không có thì **thêm dữ liệu vào seed** (đừng dùng `demo_ok` để né; hong 2026-10-05).

## 3. Cấu trúc file data (`データ/<Code頭>_<機能>.py`) — sao từ file nhỏ nhất cùng loại
Mẫu nhỏ nên mở (đọc vài dòng đầu, không đọc cả): `AW_INQU_お問い合わせ.py` (17 KB: 一覧＋詳細), `AW_REVI_レビュー・ご意見.py` (24 KB). CRUD+CSV: `AW_OPTN_…`; công ty Web: `CW_MAT_…` (54 KB). Khung gốc: `.claude/skills/screen-design-doc/assets/_ひな形.py`.
Biến cấp trên: `TITLE SHEET BASENAME IMG_PREFIX OUT_DIR CODE_NOTE SITE SYSTEM AUTHOR CREATED DEMO_FILE LOGIN DECISIONS CHANGES HIDE_ALWAYS STATIC_CSS VIEWER_CSS SCREENS H(JS tiện ích) <X>_ITEMS VIEWS`.
- `SCREENS = [{"code": "AW_INQU_001", "ja": …, "vi": …}]`. 
- Mỗi item: `{"no": "3.1", "ja", "vi", "sel": "<CSS>"|"-" , "kind": area|button|label|table|…, "trig": view|click|show, "pattern": "P-LIST", "err": ["I01"], "detail": [ja, vi], "ex": […], "demo_ok": [ja, vi]}`. `sel: "-"` = không có trên màn hình (cột CSV…). Số không đánh lại; item mới thêm cuối.
- `VIEWS = [V("001", "AW_INQU_001", "初期表示", "Ban đầu", "/ops/inquiries", L_ITEMS, note=[ja, vi], setup=…, login=…, today=…)]`. Id trạng thái liên tục 001… trong 1 機能 (không phải số của Screen Code).
- Trong tab/modal chỉ ghi item **mới hoặc đổi**; item chung ghi 1 lần ở trạng thái đầu.
- `SHEETS` = sheet phụ (dữ liệu ban đầu, CSV template). Báo `chk` = chưa xác nhận → `make.py` không build.

## 4. Screen Code và Book
`<Module2>_<Feature4>_<Seq3>` (`docs/01_仕様/画面コード規約_20261005.md`). **Module** (hong 2026-10-06, theo 規約): AW 運営, CW 法人, **OW** 委託配送先, **DA** ドライバー, SW 仕入先 (UA = ứng dụng cá nhân). Feature = 4 chữ hoa (PLAN, CORP, BILL…) — đã dùng: PLAN MODL OPTN DISC SURV REVI NOTI INQU / HOME ORDER HIST MAT STOCK BILL DLV. Seq: 001 一覧, 002 詳細, 003 登録・編集, 004 CSV取込… Đã có thì **không đổi số**, chỉ thêm.
Book (1 site = 1 file): 運営管理者Web_申請・契約(A) / _メニュー・発注(B+C) / _配送(D) / _請求・購入(E) / _お客様対応(F, đã có tên cũ `運営管理者Web_お知らせ・ご意見`) / _マスタ(G+H) / _管理・設定(I); 法人Web; 委託配送先Web; ドライバーアプリ; 仕入先Web.
`SITE`: `ops` / `corp` / `carrier` / `driver` / `supplier`. Hệ thống: `SYSTEM = {"ja": "運営管理者Web", "vi": "Web quản trị vận hành"}`.

## 6. Pattern chung (`データ/_共通パターン.py`; ghi `"pattern": "P-…"` ở item, màn hình chỉ ghi **chỗ khác pattern**)
| ID | Nội dung chính |
|---|---|
| P-LIST | Tìm bằng nút 検索/Enter (không áp dụng khi gõ, không có dấu「未適用」), es-search bên trái + クリア/検索/並べ替え bên phải, **10 dòng/trang** (10/20/50), mặc định ẩn "削除済み" (lọc được), 0 dòng = I01, nút thao tác ẩn khi không có quyền (CSV出力 hiện với mọi vai trò xem được), quay lại từ chi tiết giữ điều kiện, thứ tự mặc định: ghi theo màn / không ghi = 更新日時 giảm dần / master = ID tăng dần, lọc bảng trong chi tiết bằng dropdown (không toggle「○○も表示」), số tiền căn phải. |
| P-FORM / P-FORMBOX | Lưu = kiểm tra toàn bộ, viền đỏ + câu lỗi dưới ô (bắt buộc E01), tab đầu có lỗi mở ra, khóa nút khi lưu, trim + toàn góc→nửa góc, quá dài E04 (không cắt), E31 xung đột, Q02 khi rời mà đã sửa, S01 toast rồi về chi tiết; chi tiết chỉ xem, **lưu là nút 登録/保存 của màn**, nhiều đối tượng→「すべて」mặc định ON. |
| P-DEL | Q01→S02, lỗi E30, **xóa logic** (trạng thái 削除済み); 契約・請求書・申請 **không xóa** (dùng trạng thái). |
| P-CSV / P-CSV-IN / P-CSV-OUT | CSV取込 là **1 màn riêng, 2 bước** (không modal): khóa trùng=ghi đè, khóa trống=tạo mới, ô trống=giữ, 「-」=xóa; bước xác nhận hiện mới/cập nhật/không đổi/lỗi + エラー一覧CSV; nút chỉ hiện với vai trò có quyền CSV取込. CSV出力 = toàn bộ theo điều kiện. Định nghĩa cột: `docs/01_仕様/CSV入出力_定義_20261003.md`. Template: `CSVテンプレート/<entity>.csv`. |
| P-TAB | Tab trong màn. |
| P-HIST | Lịch sử chỉ xem; **không có 影響した拠点数・バージョン**. |
| P-MASTER | Dòng hệ thống định nghĩa sẵn ghi ở yêu cầu (運営 không tạo/xóa); 区分 là 区分マスタ (运营 thêm được); sheet phụ「初期データ」「CSVテンプレート」(`SHEETS`). |
Cần pattern mới → ghi vào `memo` và để phiên gộp thêm (không sửa file chung trong phiên cụm).

## 7. Quyết định hay gặp (đã chốt — đừng hỏi lại)
- **Quyền**: フル権限・システム管理 = CRUD mọi 機能; 6 vai trò khác thường là R (xem・CSV出力) hoặc R/U (xem・sửa・CSV出力・thao tác riêng, không tạo/xóa/CSV取込). Bảng: `docs/01_仕様/運営Web_権限表_20261003.md`. Chỉ hỏi khi 機能 có thao tác riêng (承認・公開・確定) mà vai trò chưa rõ.
- **Thuật ngữ**: 「在庫点検」→「**棚卸**」ở mọi site (2026-10-06, 受付簿 No.159). Badge=tô đầy. Xác định = xanh.
- **Ngày giờ** `yyyy-mm-dd HH:MM`; số tiền căn phải, 円; trang 10 dòng.
- **Screen**: hiển thị code, tên màn bằng JA/VI; ví dụ giá trị `ex` nên là giá trị thật có thể gặp ở production.
- **Demo/ảnh/Figma/功能一覧 chỉ để tham khảo, không phải chính** — chỗ 台帳/仕様 không có thì hỏi hong, đừng chọn theo tham khảo (CLAUDE.md).
- **Quy trình quyết định** (CLAUDE.md): quyết định của hong → ghi 台帳 trong cùng commit; quyết định cuộc họp đi qua `決定の受付簿.md` (bản mới nhất No.174; số tiếp theo **164**; sửa code xong ghi「実装済」+ commit).
- Mâu thuẫn code↔台帳: hỏi hong → sửa data hoặc ghi `demo_ok` kèm lý do. Nếu cần sửa **code** để khớp thì ghi vào `宿題` của memo, **không tự sửa code** trong phiên spec.
- Cloud thấy: `docs/01_仕様/`, `決定台帳.md`, `決定の受付簿.md`, code. Không thấy: `00_確認してほしい/`, nguyên bản biên bản, Excel, ảnh.

## 8. Mốc kích thước & cách bỏ phí
- Ước lượng cũ: S 150〜250k, M 250〜400k, L 450〜600k token (8 bước). Mục tiêu cách mới: -40%.
- Tiết kiệm: gói này thay đọc chung; không đọc mẫu cả file; 1 lượt A+B; dịch 1 lần cho cả cụm; chụp ảnh 1 lần cuối; không đọc PNG; commit nhỏ, log HANDOFF ngắn.
- Mỗi cụm tối đa 6〜7 機能 (hoặc 1〜2 L + vài S). Nếu context bị nén >2 lần → dừng, commit, báo hong chia tiếp.

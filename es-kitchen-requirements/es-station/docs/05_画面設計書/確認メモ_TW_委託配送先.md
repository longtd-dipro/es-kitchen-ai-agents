## 1. Phạm vi, 機能略, Screen Code và trạng thái (VIEWS) đề xuất

Chung cho mọi 一覧 (台帳 K・E): 10件/ページ (10／20／50), 並べ替え = mọi cột, nhớ điều kiện khi quay lại từ 詳細, 検索 = nút 検索/Enter, **không** hiện "未適用", 0件 = I01, 削除済み mặc định ẩn. Mặc định sort (台帳 E「一覧の初期の並び」= 更新日時 降順; マスタ = ID 昇順): トラブル＝受付日時 降順 ／ 見積依頼＝受信日 降順 ／ 配送スタッフ・集金管理＝ID 昇順 ／ 配送詳細内の「担当配送情報」＝納品日 降順 ／ **配送管理＝Q-12**. CSV (台帳 M-1・`CSV入出力_定義` §5): 出力 = 配送一覧・集金管理・支払の明細（月）・配送スタッフ; 取込 = 配送スタッフのみ（新規だけ・画面・2ステップ）. Lỗi lưu inline (P-FORM), Q02 khi rời form (台帳 F), E31 khi cập nhật đồng thời.

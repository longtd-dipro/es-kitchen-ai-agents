## 6. 2026-10-08 追記：請求済の子契約を締切までに直した差額（QC6）— 請求（運営E・法人A）への影響

hong 回答（QC6）：請求済の子契約の金額に効く項目を締切までに直しても、**出した請求書は取り消さない・変えない**。差額（変更後の固定額 − 請求した額。マイナス＝減額）を調整明細にして、**次に出す請求書に1行**載せる。
- 実装は運営A の領域（`lib/domain/areas/org.ts` の `updateChild`（lockedOk）・`lib/domain/adjust.ts` の `settleChange`）。調整明細（`dm.billing.adjustments`）に種類「**契約の変更**」を足しただけ。**請求書の発行・画面は変えていない**：載せ方は既存の調整明細（承認で自動でできた差額）と同じで `lib/ops/billing/fromDomain.ts` の `dmAdjLines` が ③ 調整の単発の行にする。
- 行の名前＝「{サイクル月} サイクル分の契約変更による差額（変えた項目）」（税率ごとに1行・マイナスもあり）。請求書の行の区分は「調整」のまま（新しい行の区分は足していない）。
- **運営E（請求）に確認してほしい点**：①請求の画面（③ 調整）・請求書の明細に、マイナスの調整の行が出てもよいか（承認の差額で既にマイナスはある）。②「当月請求額」「前払い」の表示は、請求済の月は**請求した額のまま**（① 費目の写しは書き換えない）。③請求書に載せたあと（invoiceId が付いた後）に直した差額は、新しい調整明細として次の次の請求書に載る。
- **法人A（法人Web の請求書）**：新しい文言・画面項目はない（行の名前が上の形になるだけ）。請求書の明細の表示に、この名前が長くて折り返しても崩れないか見てほしい。
- 未決（QC7）：契約_05 の「行の追加・削除」（確定後は反映済みの行を消せない）と締切までの編集の関係。

このファイルは、ローカルの Claude セッション（Mac）から cloud セッションへ作業を渡すためのものです。

**決定は `docs/決定台帳.md`、仕様は `docs/01_仕様/`・`docs/議事録_仕様/` を見てください（2026-10-03 から git に入っています）。** このファイルには作業の引き継ぎだけを書き、決定を写さない。cloud で見えないのは `00_確認してほしい`・議事録の原本・Excel・画像だけです。台帳にも仕様にもないことは推測せず、作業メモに「要確認」として残してください。

## 1. 守ること
- 返答・メモはベトナム語、画面の文言・用語は日本語のまま。
- データは `lib/domain`（共通データ・`dm.*`）だけを正とする。サイトごとのコピーを作らない。
- 変更後は `npx tsc --noEmit` と `POST /api/domain/check/run`（`ok:true` 必須。cloud では seed から作った DB で確認）。
- UI：金額は `lib/format/money.ts`（`1,000円`・右寄せ・（税込）/（税抜））、日付は `lib/format/date.ts`（yyyy-mm-dd / yyyy-mm）、ステータス色は `lib/format/status.ts`、CSV は `lib/csv` と `components/csv`。新しい独自スタイルを作らない（既存クラスを使う）。
- 1 コミット = 1 まとまり。main に直接 push してよいのは、ユーザーが許可したときだけ（基本はブランチ＋PR）。
- 実在のお客様データは入れない（seed は架空）。

## 2. cloud 向きの残作業（コードだけで完結）
1. **レスポンシブ・文字サイズ**
   - 全 CSS が px 指定（rem が 0）のため、Chrome/Safari の「フォントサイズ」設定が効かない。ルートは 14px のまま、文字サイズと主要な余白を rem に置き換える（見た目は既定で変えない）。
   - 1280 / 1366 / 1440 / 1920 幅、ブラウザの文字サイズ「大」「特大」、ズーム 125/150% で、ページ全体の横スクロール・はみ出し・文字の重なりがないこと（表は表の中で横スクロール可）。
   - 大画面：フォーム・文章は最大幅をつける。表は全幅でよい。
2. **API の権限（6-1）**
   - いまは API がアカウントの範囲を見ていない。ログイン中のアカウント（法人・拠点・委託配送先・仕入先・ドライバー・運営）が、自分の範囲のデータだけ読める・書けるようにサーバー側で制限する。運営は役割（ops.full / ops.purchasing など）で制限。

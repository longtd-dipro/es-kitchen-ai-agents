# 代替品（商品不良対応）仕様 確認シート

## 1. 発覚前・発覚後による対応の切り替え 【ご確認のみ】

**弊社の認識：** 商品不良は「発覚日」を境に対応が分かれる。
- 発覚日を含む納品済みの顧客（例：7/29発覚なら27・28・29日納品分）＝ 既納品分として補償対象。
- 発覚後の未納品顧客（例：30・31日以降）＝ 該当商品を発送から抜き、「納品分に含まれません」と連絡。

| No | 確認内容 | ご回答欄 |
|---|---|---|
| 1-1 | 発覚日基準で「納品済み」「未納品」を分ける認識で相違ないか。 | |
| 1-2 | 未納品分は該当商品を抜いて通知する運用で問題ないか。 | |

---

## 2. 既納品分の「補償」2パターン 【要ご確認】

**弊社の認識：** 既納品分の補償は2通り。
1. 全数量保証：注文数量すべてを別商品で保証。
2. 残在庫分のみ保証：在庫として残っている分のみ保証。

| No | 確認内容 | ご回答欄 |
|---|---|---|
| 2-1 | 補償方式はこの2パターンで網羅されているか（他にないか）。 | |
| 2-2 | どちらを適用するかは、誰が・どの基準で選択するか。 | |

---

## 3. 入荷形態（月2回入荷／毎日入荷）による差異 【要ご確認】

**弊社の認識：** 鳥の唐揚げのような月2回入荷商品と、生鮮サラダのような毎日入荷商品がある。以前「毎日になるだけで大きくは変わらないかもしれない」とのお話でしたが、結論は保留のままと理解しています。

| No | 確認内容 | ご回答欄 |
|---|---|---|
| 3-1 | 入荷形態の違いで代替品の送り方を変える必要はあるか（不要か）。 | |

## 4. 不良の範囲（ロット単位／全ロット） 【ご確認のみ】

**弊社の認識：** ロット単位の不良もあれば、商品自体の問題で全ロットが対象になることもある。かぼちゃサラダのように、生鮮でも全ロット対象となるケースがある（＝生鮮＝ロット単位限定と決め打ちしない）。

| No | 確認内容 | ご回答欄 |
|---|---|---|
| 4-1 | 「ロット単位」「全ロット」を選べる形で相違ないか。 | |
| 4-2 | 生鮮商品でも全ロット対象を選択できる必要があるか。 | |

---

## 5. 代替品の納品タイミング（発送回の選択） 【要ご確認】

**弊社の認識：** 現行のESステーションでは同月内の代替品送付が指定できず翌月以降のみ。実運用では同月発送もあり、150プランの例のように「第1回発送の不良を第2回発送に含める」など、**どの発送回に含めるかを選べるようにしたい**というご要望と理解しています。

| No | 確認内容 | ご回答欄 |
|---|---|---|
| 5-1 | 代替品を含める「発送回」を選択できる仕様が必要か。 | |
| 5-2 | 同月・翌月・複数回にまたがる場合の指定ルールに希望はあるか。 | |

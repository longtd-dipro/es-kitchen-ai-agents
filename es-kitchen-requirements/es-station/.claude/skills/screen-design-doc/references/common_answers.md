# 共通の話題 — 答えの場所（画面ごとに聞き直さない）

**答えそのものはここに書かない**（二重管理になる）。「どこを見れば答えがあるか」だけ。台帳は `docs/決定台帳.md`。
この表の話題は、**機能のスレッドでは聞かない**。台帳・基準に答えがあれば適用、なければ受付簿に【共通質問】で1行（状態＝受付）。

| 話題 | 答えの場所 |
|---|---|
| 一覧（1ページの件数・並べ替え・検索ボタン・0件・削除済みの見せ方） | 台帳 K「一覧の決まり」・M-1「検索」「削除」 |
| 日付・年月・日時の書き方／日付入力の部品 | 台帳 M-1「日付の書き方」・`input_standard.md`「日付・時刻」 |
| 金額（桁・表示・税込税抜・税率） | 台帳 M-1「金額」・`input_standard.md`「数値」 |
| 文字数（1行・住所・備考・カナ・郵便・電話・メール・URL） | `input_standard.md`「文字」・台帳 M-1「メモ・備考」「文字」 |
| 数量の桁（台数・回数・食数・発注数…） | 台帳 M-1「数量の桁」・`input_standard.md`「数値」 |
| ID・コードの付け方 | 台帳 M-1「ID・コード」・K「申請番号の形」・`画面コード規約_20261005.md` |
| 添付ファイル | 台帳 M-1「添付ファイル」・`input_standard.md` |
| ログイン期限・保存時に切れたとき・同時編集 | 台帳 M-1「ログインの期限」「同時に編集」 |
| 削除（論理削除・状態名・確認の文言） | 台帳 M-1「削除」・`message_style.md`（Q01） |
| 権限（誰が見る・作る・直す・削除・CSV） | 台帳 K「運営の権限の読み方」「権限のない画面」・`運営Web_権限表_20261003.md` |
| メッセージの書き方・出し方・ID | `message_style.md`・`_共通_メッセージ.py`・台帳 K |
| 状態のバッジの色・言葉・単位 | 台帳 M-1「状態のバッジ」「言葉・単位」 |
| CSV 出力・取込 | 台帳 M-1「CSV 出力」・`CSV入出力_定義_20261003.md` |
| 入力中に離れるときの確認（離脱確認） | 各画面 DECISIONS「離脱の確認（Q02）」＝全サイト共通で出す（Message List No.25） |
| 画面の共通部品（ヘッダー・サイドバー・パンくず・ボタンの位置と名前・タブ・モーダル・トースト・0件／読み込み／エラーの表示・戻る） | `データ/_共通パターン.py`（設計書の「共通パターン」に1回だけ書く）・台帳 K・`message_style.md`。新しい画面でも**同じ部品は同じ動き**。違いが要るときだけ聞く |
| 言語 | 台帳 K「ベトナム語」＝日本語固定 |
| 使われない項目・要らない項目 | 台帳 M-1「使われない項目」 |
| 仕様の版・改訂履歴 | 台帳 M-1「開発に渡す仕様の版」 |

見つからない／書いてあることが足りない共通の話題は、**聞く前に**：
1. `kd_ask.py gate "語 語 | 質問"`（他のスレッドの未マージ分も見る）
2. なければ受付簿に【共通質問】（1行・状態＝受付・推奨＝仮）。ユーザーへは「共通質問がたまったとき」に**まとめて1回**
3. 答えが出たら、台帳 M-1 か K に1行（同じコミット）。**この表にも行を足す**（場所だけ）

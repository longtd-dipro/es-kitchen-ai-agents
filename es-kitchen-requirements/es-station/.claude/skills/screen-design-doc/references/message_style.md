# メッセージの書き方（システム全体で揃える）

目的：同じ意味のメッセージは、どの画面でも同じ言い回しにする。お客様（法人・拠点）には失礼にならず、
社内の利用者（運営・ドライバー・委託配送・仕入先・倉庫）には必要なことが短く伝わるようにする。

`make.py --check` がこの決まりの一部（長さ・使わない表現・文末・差し込み・同じ文言の重複）を自動で確かめる。
自動で確かめられないもの（意味が足りているか・言い回しの統一）は、文言を足すたびに Claude が下の表と見比べる。

## 1. 2つの書き方

| | 法人・拠点向け（ja_c） | 社内向け（ja_o） |
|---|---|---|
| 使うサイト | 法人Web（法人アカウント・拠点アカウント） | 運営管理者Web・ドライバーアプリ・委託配送・仕入先・倉庫 |
| 調子 | 丁寧語＋お客様の動作には「ご〜ください」「お〜ください」 | です・ます。敬語の上乗せはしない。命令口調・体言止めにしない |
| 入力のお願い | 〜をご入力ください。／〜をお選びください。 | 〜を入力してください。／〜を選択してください。 |
| できないこと | 〜はご利用いただけません。 | 〜できません。／〜する権限がありません。 |
| 失敗 | 保存できませんでした。時間をおいて再度お試しください。 | 保存できませんでした。再度お試しください。 |
| 使わない | 「〜してください」だけの素っ気ない形、専門用語・内部コード（RF000001 など）、責める言い方（「誤っています」） | 「申し訳ございません」「お手数ですが」「〜させていただきます」「いただけますでしょうか」 |
| 共通で使わない | 「下さい」（→ください）、「〜せよ」「〜しろ」「〜すること。」、「エラーです」だけ、「不正な」、「！」 | |

ベトナム語（vi）は1つだけ書く（開発向け）。「Vui lòng …」で始める丁寧な形。画面の文言・ボタン名は「"…"」で日本語のまま入れてよい。

## 2. 中身の決まり

1. **何が起きたか ＋ どうすればよいか** の順。どうすればよいかが明らかなら「何が起きたか」だけでよい（例：「保存しました。」）
2. **長さ**：インライン（項目の下・表の下）とトーストは 40 文字まで。ページ内・モーダルは 1 文 80 文字まで。長くなるなら画面の説明文に移す
3. **項目名は差し込み**（`{項目名}`）。項目名を文言に直接書かない。ベトナム語は `{tên mục}`
4. **数字は半角**、単位は「件」「文字」「MB」。金額は「¥1,000」
5. **確認モーダル**は「タイトル（〜しますか？）／本文（結果どうなるか）」。ボタンは動作の名前（「削除する」「破棄する」）。「はい／いいえ」にしない
6. **同じ意味は同じ ID**：新しく足す前に `_共通_メッセージ.py` に近いものがないか探す。言い回しだけ違うものを作らない
7. **用語を揃える**：メールアドレス（Eメール・メアドにしない）、ログイン、お申し込み（法人向け）／申込（社内向け）、拠点、納品先。**「ESキッチン」＝お客様（運営会社）の名前・「ES STATION」＝システムの名前**（ES の決定 2026-10-05。「ESSTATION」「ESステーション」は使わない）。迷う用語はユーザーに確認して下の表に足す

## 3. 標準の言い回し（_共通_メッセージ_ひな形.py の中身）

| ID | 場面 | 法人・拠点向け | 社内向け |
|---|---|---|---|
| E01 | 必須（入力） | {項目名}をご入力ください。 | {項目名}を入力してください。 |
| E02 | 必須（選択） | {項目名}をお選びください。 | {項目名}を選択してください。 |
| E03 | カタカナ | {項目名}は全角カタカナでご入力ください。 | {項目名}は全角カタカナで入力してください。 |
| E04 | 文字数 | {項目名}は{n}文字以内でご入力ください。 | {項目名}は{n}文字以内で入力してください。 |
| E07 | メール形式 | メールアドレスの形式をご確認ください。 | メールアドレスの形式が正しくありません。 |
| E09 | 重複 | この{項目名}はすでに登録されています。 | （同じ） |
| E30 | 保存失敗 | 保存できませんでした。時間をおいて再度お試しください。 | 保存できませんでした。再度お試しください。 |
| E31 | 同時更新 | ほかの方が先に更新しました。画面を読み込み直してください。 | ほかのユーザーが先に更新しました。再読み込みしてください。 |
| E32 | 権限 | この操作は現在のアカウントではご利用いただけません。 | この操作を行う権限がありません。 |
| Q01 | 削除の確認 | 削除しますか？／削除すると元に戻せません。 | （同じ） |
| Q02 | 破棄の確認 | 入力内容を破棄しますか？／保存していない内容は失われます。 | （同じ） |
| S01 | 保存完了 | 保存しました。 | （同じ） |
| I01 | 0件 | 該当するデータがありません。条件を変えてお試しください。 | 該当するデータがありません。 |

## 4. Message List との関係

- Message List（お客様の Excel）が文言の正。`make.py` が自動で読み、「一致／文言が違う／未登録」を出す
- 「文言が違う」ものは **作る前に** ユーザーに確認する（Message List に揃えるか、この決まりに沿って Message List を直す提案をするか）。決まるまでは `diff` に書いておけば make.py が止める
- Message List にないものは「Message List への追加案」シートに出る（貼り付けて番号を振る）
